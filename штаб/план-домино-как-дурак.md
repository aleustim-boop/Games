## 2. Этапы (один этап — 1–2 файла)

**Д-1. Лобби: вид (домино.html, style-домино.css).** Верхняя строка `.верх-игры` в трёх экранах-лобби; карточка профиля с `лобби-рейтинг`/`лобби-место`, без «Мой профиль и результаты»; плашка `дом-продолжить` → `плашка-возврата`; рамка 16:10; подпись в листе «Рекорды». Проверка node: tests/домино-как-дурак.js (новый, по образцу шашки-как-дурак.js) — узлы найдены и без серии/старой подписи, нет `.дом-верх` в лобби, `aspect-ratio:16/10` в css. Ломающий: копии html/css со старым видом (запуск с путями в аргументах) — краснеет; ноль найденных узлов — провал.

**Д-2. Лобби: место в рейтинге (js/домино-экран.js).** `освежитьМесто()` по образцу js/шашки-лобби.js (словаМеста, класс `--нет`), вызов при показе лобби и при `load`. Проверка node: тот же tests/домино-как-дурак.js ищет `ЭкранРейтинга.моёМесто('домино')` и переключение `--нет`; ломающий — копия без вызова. Лобби-настольных.js не меняется.

**Д-3. Итог: разметка (домино.html, style-домино.css).** В подвал `дом-результат`: «Реванш» (`дом-реванш`, спрятана), «Сыграть с ботом» (`дом-ещё-с-ботом`, спрятана), «Похвастаться» (`дом-похвастаться`, спрятана), «Рекорды» (`дом-рекорды-итог`), «В лобби» → «В меню» (id `дом-в-лобби` оставить: на нём тесты), строка `дом-итог-рейтинга`, подпись реванша. Узкие окна: подвал и так в прокрутке, высоту кнопок не менять без снимка. Проверка node: расширить tests/домино-как-дурак.js на кнопки итога; ломающий — копия без «Реванш».

**Д-4. Итог: поведение (js/домино-экран.js).** «Сыграть ещё»/«Реванш»: у стола с людьми после конца партии подпись «Реванш» (`ещё`), с ботом — «Играть ещё» (новая партия); «Сыграть с ботом» — при `сетевой.соперникУшёл` (новая партия с ботами теми же настройками); «Похвастаться» — победа в Telegram, как js/шахматы-экран.js (`Сеть.похвастаться` с игрой `домино`, мест → `игроков`); «Рекорды» — `история()`; «В меню» — как «В лобби» сейчас; «+N к рейтингу» — ответ `ОчкиРейтинга.сдать` через `словаИтога`. Только конец партии, не конец раунда. Проверка node: песочница vm не годится на 660 строк с DOM — читаем код как текст (как шашки-как-дурак.js): привязки кликов, `словаИтога`, `Сеть.похвастаться`; ломающий — копия без привязки «Реванш». Тест `tests/домино-как-дурак-браузер.js` прогнать (он существует, 410 строк, чужой по этапу Э10: если он краснеет на новые кнопки — спросить штаб, файл не мой).

**Д-5. Снимки и свод (tests/домино-как-дурак.js, tests/снимки/ — только запись).** Тестер: снимки лобби 390 px и итога (раунд и конец партии, с ботом) на тестовом порту, не 8790; перед браузером `node штаб/браузер-занят.js`. Снимок оценивает смотритель на sonnet (мелкое видит плохо). Ломающий для вида — копия css со старой пропорцией.
