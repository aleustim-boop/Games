## Этапы

**Этап 1. Сервер: третий вид «приглашение»** (файл: server/сервер.js)
- Новая функция `сообщениеВПриложение(тело, кто)`. От клиента берём только `вид: 'приглашение'` и `игра` (сверяем по списку server/названия.js; нет в списке — приглашение общее). Присланную ссылку **не читаем**.
- Ссылку собирает сервер: `https://t.me/<имя бота из getMe>?start=invite` или `?start=invite_<метка игры>` (только латиница, до 64 знаков — предел ?start=). Имя бота уже узнаётся сервером (`имяБотаВTelegram`); не узнали — отказ, клиент уйдёт в запасной путь.
- Имя пригласившего — `first_name` из ПРОВЕРЕННОЙ подписи, обрезать до 32 знаков, убрать переводы строк. Нет имени — «Друг».
- Текст: «<Имя> зовёт сыграть в <вИгру> — заходи!» или общий «<Имя> зовёт в настольные игры прямо в Telegram — заходи!». Кнопка «Играть» (url на ссылку выше).
- Вид карточки: `type: 'photo'` (photo_url + thumbnail_url — обложка игры с опубликованного адреса, caption — текст, та же кнопка). Адрес картинок — постоянная в сервере (адрес Pages + путь). Нет обложки у игры — общая картинка (см. вопрос 2), нет и её — прежняя `article` без картинки.
- В строке 1468 выбор из трёх видов; пауза 3 с действует и тут.

**Этап 2. Браузер** (файл: js/похвастаться.js)
- `поверхСГолымТелом` получает тело `{ initData, вид: 'приглашение', игра }`; `пригласитьВПриложение(игра)` принимает необязательную игру. Откат на список чатов и буфер не трогаем.
- Если выбрана игра — запасная ссылка тоже `?start=invite_<метка>` (сходится с сервером).
- Кнопки в лобби игр пока зовут без игры (общее приглашение) — передачу игры добавить отдельной мелочью по решению владельца.

**Этап 3 (по желанию). Бот** (файл: bot/бот.js): на `start=invite_<метка>` в приветствии кнопка «Играть» ведёт сразу в эту игру (startapp=метка). Без этого этапа гость попадает на витрину — тоже рабочий путь.

## Риски
- Bot API: у savePreparedInlineMessage сообщение живёт ограниченное время (около часа?), поэтому готовим на каждое нажатие; пауза 3 с защищает от частых просьб.
- Картинка: photo_url должна быть JPEG и доступна Telegram; битая ссылка → Telegram отказывает → тихий откат на список чатов. Проверять опубликованный адрес картинки.
- Старый Telegram (< 8.0) — видит список чатов, как сейчас.
- Кэш: js/похвастаться.js подключён на нескольких страницах — штаб поднимает `?v=` у ВСЕХ.
- Сервер: новый вид работает только после перезапуска боевого 8790 — делает штаб при 0 комнат. Порядок: сервер раньше клиента (новый клиент со старым сервером просто откатится — не страшно).
- Имя из Telegram — чужой текст в нашем сообщении: только из подписи, обрезка, без ссылок-разметки (parse_mode не ставим).
