# Языки на всех страницах — общее задание словаря игры

Слова владельца (05.10 08:11): «необходимо перевести все страницы а не только главную».

## Как устроен перевод
- `js/языки.js` — общий словарь. Ключ — русская фраза ровно так, как её видит игрок; строка словаря: `русский|українська|English`.
- `js/язык-интерфейса.js` сам обходит страницу и следит за изменениями: любой текстовый узел и атрибуты aria-label, title, placeholder, alt, чей текст ЦЕЛИКОМ совпал с ключом (пробелы по краям и повторы пробелов не важны), заменяется переводом. Код игры для перевода менять НЕ надо и нельзя.
- Не переводятся: имена игроков, коды комнат, узлы с `data-no-translate`.
- Словарь игры — отдельный файл `js/языки-<игра>.js`. Он зовёт `Языки.добавить(текстСтрок)` (строки «ru|uk|en», по одной на строку) и `Языки.добавитьШаблоны([[RegExp, 'uk с $1', 'en с $1'], …])` для фраз с именами и числами. Образец обоих видов — `js/языки.js`, строки 1–10 и 394–466 (больше оттуда читать не надо).
- Файл должен работать и в браузере (`window.Языки`), и в node (`require('./языки')`) — смотри, как это сделано в конце `js/языки.js`.
- Страницу к словарю подключает штаб, html исполнитель не трогает.

## Что собрать в словарь игры
Всё, что игрок видит на странице игры по-русски: тексты в html страницы, строки в js-файлах игры, фразы, которые присылает сервер (`server/игры/<игра>.js`), правила «Как играть», подписи кнопок, подсказки, итоги партии, ошибки.
- Файлы целиком не читать. Фразы доставать поиском строк с кириллицей (Grep по файлу, вывод кусками), html — только текст между тегами.
- Фраза, склеенная в коде из кусков (`'Ход: ' + имя`), в DOM приходит одним узлом — в словарь идёт шаблон на всю фразу, а не кусок.
- Фразы, которые уже есть в `js/языки.js` (проверь Grep'ом по ключу), повторять не надо.
- Перевод — живой, короткий, как в игре: кнопка должна остаться кнопкой, а не предложением. Украинский — литературный, без русизмов. Игровые термины — принятые (шах/мат — check/checkmate, дамка — king, рыба — blocked game и т. п.).
- Символ `|` внутри фразы недопустим: такая фраза идёт шаблоном.

## Проверка (в tests/, чистый node, без браузера)
`tests/языки-<игра>.js`:
1. у каждой строки словаря три непустые части, ключи не повторяются, шаблоны — RegExp с переводами, где `$n` не больше числа скобок;
2. покрытие: проверка сама достаёт из html страницы и js-файлов игры строки с кириллицей (тем же приёмом, что исполнитель) и требует, чтобы каждая была в словаре, подходила под шаблон или стояла в явном списке «не переводим» с причиной (имена, отладка, комментарии кода). Ноль найденных строк — провал, не пропуск;
3. умеет краснеть: ломающий запуск берёт КОПИЮ словаря во временной папке (путь доводом), вычёркивает из неё строку и требует провала. Настоящий файл не портить.

## Правила
Одна команда — одно действие: без склеек через `&&`, `;` и переводы строк; без python, tar, rm -rf. git checkout/restore/stash запрещены, не коммитить. Правки своих файлов — Write/Edit. Комментарии по-русски. Память — до 80k: читать кусками. Если охрана файлов отказала в первые секунды — подождать и повторить один раз.
Отчёт до 12 строк: сколько строк и шаблонов в каждом словаре, вывод проверок, на чём покраснел ломающий запуск, что сознательно не переведено и почему, что не проверено.
