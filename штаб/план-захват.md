## Решения штаба по плану (раздел 0.5)
1. Фразы — свой файл `js/захват-знаки.js`.
2. Холст кладёт только готовые рисунки Кодекса; числа, имена, метки — узлами страницы, вид в `style-захват.css`.
3. Тихая дверь черновика — `POST /черновик`, метод `Сеть.отправитьЧерновик`.
4. При приёме В1 штаб вписывает «захват» в ДОЛГ `tests/у-каждой-игры-рейтинг.js` («строится, плитки нет до сдачи»); вычёркивает на этапе С.

## Условия от ревью Б10/Б15 (вписывать в задания)
- **А8 (серверный файл игры):** `require('../../js/захват-знаки.js')`, НЕ деберц-знаки — иначе броски 20–22 сервер примет за фразы деберца. Проверка этапа: бросок №20 без адресата → отказ «Выберите, в кого бросить».
- **Кнопка «Похвастаться» на экране «Захвата»** — не раньше Б8а: до него сервер (server/названия.js) отвечает «в подкидном дураке» и ссылка ведёт на дурака. В Б8а — строка в названиях со словами «в захвате» + МЕТКИ_ИГР 'zahvat' в js/похвастаться.js.
- Мелочи на потом: устаревший комментарий «берёт каталог при загрузке» в нарды.html ~858 и шахматы.html ~845; в tests/сказать-каталог.js прогон, где подключён только захват-знаки.js.
