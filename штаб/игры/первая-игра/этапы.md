### 0.2. Как устроены проверки

- Все проверки — `tests/захват-*.js` на node, кроме двух браузерных (Г2 и Г4). Пишет их тестер, в
  `tests/`. Слова «браузер-робот» и «chromium» в тексте node-проверки **запрещены**: по ним сводный
  прогон `tests/прогон-всего.js` считает файл браузерным. Общий помощник проверок (если появится,
  например `tests/захват-помощник-комнаты.js`) вписывается в список помощников сводного прогона
  (около строки 73) — это правка общего файла, её делает штаб при приёме.
- **Ломающий запуск портит копию.** Каждая проверка принимает довод `--файл <путь>` (или
  `--папка <путь>` для серверных): вместо настоящего файла берётся копия из временной папки
  исполнителя. Тестер делает копию, вносит в неё названную порчу, запускает проверку с доводом и
  показывает в отчёте покраснение. Настоящий файл не портится даже на минуту.
- **Копия для серверных проверок — как в `tests/возврат-за-стол.js`** (строки 162–170): папки
  `server/` и `js/` копируются **целиком** во временную папку, порча вносится в файл копии, сервер
  поднимается `require`'ом из копии. Тогда все относительные `require` (`../../js/захват-правила.js`,
  `./игры/реестр.js`) находят соседей из той же копии. Подмен через `module._compile` и
  `require.cache` не делать.
- **Проверки комнаты** (случаи 16, 30–32, 34–37) поднимают сервер `require`'ом в том же процессе, как
  `tests/возврат-за-стол.js`, на свободном порту, **не на 8790**. При `require` сервер память на диск и
  так не пишет; ключ `--без-памяти` (разбирается в `server/сервер.js` около 281) нужен только при
  запуске сервера командой (`node server/сервер.js …`).
- **Часы.** Своих часов у `server/комнаты.js` нет, `Date.now()` в нём десятки раз. Проверка комнаты
  сама подменяет `Date.now` **и** `setTimeout`/`clearTimeout` на поддельные и двигает время вручную,
  по секундам. `tests/поддельный-браузер.js` подменяет только `Date` (поддельные часы) — `setTimeout`
  тестер подделывает сам и в браузерных стендах.
- **Ноль найденного — провал.** Если проверка не нашла случай, узел, ключ или вызов — она краснеет.
- Экраны без сети проверяются на node с `tests/поддельный-браузер.js` (поддельные хранилище, облако,
  часы, документ). Холст — поддельный объект, который записывает все вызовы и свойства (В4).

### 0.3. Что параллелится

Правило: **разные файлы — параллельно, один файл — строго по очереди.** Карта зависимостей:

```
А1 ✓ ─► А2 ✓ ─► А3 ─► А4 ─► А8 ─► А9а ─► А9б ─► Б2 ─► Б3а ─► Б3б ─► Б4а ─► Б4б ─► Б5а ─► Б5б
            └──► А5 (идёт; партию до конца проверяет после А4)                              │
А6 ✓, А7 ✓, А10 ✓, Б1 ✓ — приняты.   Б7, Б10, Б15 — в любой день, параллельно со всем       │
                                                                                            ▼
                                             Б5б ─► Б6 сеть.js ─► Б8а названия+game.js ─► Б8б подбор ─► Б9
А4 + А6 ─► В1 страница+скрытая запись ─► В2 оформитель
В1 ─► В5 экран-1 ─► В8а цикл ─► В8б выбыл и итог ─► В8в подсказки      (В8а ждёт ещё В3, В6, А5)
В1 + А2 ─► В6 стол-1 ─► В7 жесты;    А3 ─► В3 раскрытие;    В1 ─► В4 карта-вид-1
Б6 + В6 ─► В9 онлайн ─► В10 «Сказать» (ждёт Б15)
Пачка Кодекса ─► Б13 значок ✓ ─┐
              ─► Г1 ─► Г2 ─► Г3 ─┤
В8б + В9 + Б13 ─────────────────► Б11 реестр-рейтинг ─► (штаб перезапускает сервер) ─► Б12 витрина ─► Б14 ─► С
```

Самый длинный путь — правила → сервер игры (А8, А9а, А9б) → шесть этапов `server/комнаты.js` и
`server/сервер.js` → сеть → онлайн-экран. Его и держать занятым без перерывов.

### 0.5. Решения в плане

1. **Фразы — свой файл `js/захват-знаки.js`** (принят, А10). Смайлики и броски в нём — в том же
   порядке, что у `js/деберц-знаки.js` (картинки бросков ищутся по ключу; `tests/захват-знаки.js` это
   уже проверяет), фраз 8 вместо 11. **Сервер правки не требует:** `послатьЗнакВнимания`
   (`server/комнаты.js` около 2819) уже берёт каталог из договора игры — `играКомнаты(комната).знаки`
   (около 2825). Браузеру нужна правка общей панели — этап Б15.
2. **Холст и слой узлов — только готовые рисунки Кодекса.** На холст `drawImage` кладутся готовые
   рисунки сот, кромок, границ края, выбора, целей, стрелок, вспышек, трещины и моря (графика.md
   4.2–4.5). **Шайбы войск (№ 18 `шайбы.webp`), шайбы столиц (№ 19 `шайбы-столиц.webp`) и пилюля
   метки (№ 29 `пилюля-метки.webp`) — тоже готовые рисунки Кодекса**: они лежат фоном узлов слоя
   подписей поверх холста. Шайба — узел с классом, который выбирает кадр листа (кадр 192×192, на
   экране 26 px; столица — кадр 256×256, на экране 32 px); пилюля — `border-image` с краями по 32 px
   (середина тянется по тексту, края — нет). **Это не CSS-круги:** у узлов шайб и пилюль нет
   `border-radius`, `background-color`, `box-shadow`, градиентов. Цвет игрока в полосе, в итоге и у
   столицы — кадр `значки.webp` (№ 20), не полоска цвета. **До пачки шайбы, пилюли и значки не
   показываются вовсе** (узлы есть, рисунка нет — узел скрыт). Текст (числа, «+3», имена) — узлами
   с классами; размеры и цвета — в `style-захват.css` (из js нельзя задавать вид, CLAUDE.md).
3. **Маршрут тихой двери — `POST /черновик`** рядом с `case '/ход'` в `server/сервер.js` (около
   строки 1097), проверка входа та же, что у `/ход`. Метод браузера — `Сеть.отправитьЧерновик(раунд,
   черновик)` рядом с `отправитьХод` (`js/сеть.js` около 7354). Имена закрепляются в Б5б/Б6.
4. **Страница в корне — со скрытой записью реестра** (решение штаба по п.1 ревью).
   `tests/у-каждой-игры-рейтинг.js` требует запись в `js/игры-реестр.js` для **каждой** страницы
   `*.html` в корне (строки 211–214) — ДОЛГ от этого не освобождает; а долг за игру, которой нет ни в
   реестре, ни на витрине, сам считается провалом (356–358). Поэтому на **В1** вместе со страницей
   разработчик добавляет в реестр **скрытую запись** (см. В1), а штаб при приёме вписывает «захват» в
   ДОЛГ с причиной «строится, плитки нет до сдачи». Б11 запись дополняет, на С строка ДОЛГа
   вычёркивается.
5. **Онлайн до О3 без порога 4 раундов** (ТЗ 18, решение штаба по ревью-3) — запись реестра с
   `вес: 0.5` и `бот: { партияНеКорочеСекунд: 60, … }` (поля — внутри `бот`, см. Б11).
6. **Панель «Сказать» получает каталог игры вторым доводом** (решение Джо по п.2 ревью; штаб
   разрешил выбрать). Правка общего `js/деберц-сказать.js` [Р] (этап Б15): каталог берётся внутри
   фабрики — `window.ДеберцСказать = function (контекст, каталог) { const З = каталог ||
   window.ДеберцЗнаки; … }`. Старые вызовы (домино, катан, морской бой, онлайн-лобби) не меняются.
   «Захват» зовёт `ДеберцСказать(контекст, window.ЗахватЗнаки)` сам, как домино. Почему не подмена
   `window.ДеберцЗнаки` на странице «Захвата»: она держится на порядке подключения скриптов (любая
   перестановка — молча фразы деберца, и номера бросков съедут: у деберца 11 фраз, у нас 8), под
   именем «Деберц» лежал бы чужой список, и пришлось бы трогать принятый А10.
7. **Облачко фразы — 2 секунды, как во всех играх** (общая панель гасит его через 1,6 с и убирает в
   2 с), а не 3 с из ТЗ 6. Правило «все игры выглядят одинаково» выше; ТЗ 6 штаб поправит строкой.
8. **Кнопка «Сказать» — только в партии по сети** (как у монополии: видна при
   `вид.знакиВниманияЕсть`). Без сети за столом одни боты, а боты молчат (ТЗ 6), — сказать некому.
