# «Захват» — план кода этапами (шаг 5 протокола)

Джо, 01.10. Основа: `тз.md` (после четырёх ревью), `графика.md`, устройство домино и общих файлов.
Штаб превращает этот план в `штаб/план-захват.md` и раздаёт этапы. Джо кода не пишет.

**Как читать.** Этап — 1–2 файла, до пары часов работы исполнителя. У каждого этапа: цель, файлы,
что сделать (со ссылками на разделы ТЗ), когда готово, проверка. В каждой проверке есть **ломающий
запуск** — порча копии файла, на которой проверка обязана покраснеть. Пометка **[Р]** значит
«ревьюер полной модели обязателен» (общий файл, сервер, сеть). **[К]** — этап ждёт рисунков
Кодекса. **[О]** — нужен оформитель (новый экран). **[Н]** — нужен игрок-новичок.

Всего **38 этапов**: 10 — правила, бот, фразы, память, звук и сервер игры (фаза А); 14 — общие
файлы (фаза Б; из них Б13 — рисунок Кодекса, Б14 — строка README); 9 — страница и экраны до пачки
рисунков (фаза В); 4 — после пачки (фаза Г); 1 — сдача. Плюс Б3ф — только если владелец выберет
«фразы одному».

## 0. Общие договорённости для всех этапов

|---|---|---|---|

приходят доводом). Сервер берёт правила через `require('../../js/захват-правила.js')` — правила не
раздваиваются (CLAUDE.md, «Договоры»).

### 0.2. Как устроены проверки

- Все проверки — `tests/захват-*.js` на node, кроме двух браузерных (Г2 и Г3). Пишет их тестер, в
  `tests/`. Слова «браузер-робот» и «chromium» в тексте node-проверки **запрещены**: по ним сводный
  прогон `tests/прогон-всего.js` считает файл браузерным. Общий помощник проверок (если появится,
  например `tests/захват-помощник-комнаты.js`) вписывается в список помощников сводного прогона
  (около строки 73) — это правка общего файла, её делает штаб при приёме.
- **Ломающий запуск портит копию.** Каждая проверка принимает довод `--файл <путь>` (или
  `--комнаты <путь>` для комнат): вместо настоящего файла берётся копия из временной папки
  исполнителя. Тестер делает копию, вносит в неё названную порчу, запускает проверку с доводом и
  показывает в отчёте покраснение. Настоящий файл не портится даже на минуту.
- Для общих серверных файлов с относительными `require` копия подставляется так: текст копии
  компилируется как модуль с путём настоящего файла (`module._compile(текстКопии, настоящийПуть)`)
  и кладётся в `require.cache` до `require('../server/сервер.js')` — тогда соседние `require`
  находят свои файлы.
- **Проверки комнаты** (случаи 16, 30–32, 34–37) поднимают сервер в том же процессе, как
  `tests/возврат-за-стол.js`, на свободном порту с `--без-памяти`, **не на 8790**. Часы подменяются в
  самой проверке: `Date.now` и `setTimeout`/`clearTimeout` заменяются на поддельные (своих часов у
  `server/комнаты.js` нет, `Date.now()` в нём 34 раза). Время двигается вручную, по секундам.
- **Ноль найденного — провал.** Если проверка не нашла случай, узел, ключ или вызов — она краснеет.
- Экраны без сети проверяются на node с `tests/поддельный-браузер.js` (поддельные хранилище, облако,
  часы, документ). Холст — поддельный объект, который записывает все вызовы.

### 0.3. Что параллелится

Правило: **разные файлы — параллельно, один файл — строго по очереди.** Карта зависимостей:

```
А1 карты ─► А2 правила-1 ─► А3 правила-2 ─► А4 правила-3 ─► А8 сервер-игры-1 ─► А9 сервер-игры-2
                 └────────► А5 бот (после А2, параллельно с А3–А4; итог сверяет после А4)
А6 память, А7 звук, А10 знаки, Б1 имя игры, Б7 «Сдаться» — с первого дня, параллельно со всем

А9 ─► Б2 реестр сервера ─► Б3 комнаты-1 ─► Б4 комнаты-2 ─► Б5 тихая дверь (комнаты + сервер)
                                                                 └─► Б6 сеть.js ─► Б8 названия и подбор
А4 + А6 ─► В1 страница ─► В2 оформитель ─► В4…В8 экраны ─► В9 онлайн (после Б6)
А4 ─► В3 раскрытие;   В1 ─► В4 карта-вид-1 (только расчёт раскладки)
Пачка Кодекса ─► Г1 карта-вид-2 ─► Г2 вид и замер ─► Г3 новичок ─► Б12–Б14 витрина, README ─► С сдача
```

Сразу в первый день можно пустить пятерых: **А1, А6, А7, А10, Б1** (и Б7 — шестым, если свободен
ревьюер). Самый длинный путь — правила → сервер игры → три правки `server/комнаты.js` → сеть →
онлайн-экран; его и надо начинать первым.

### 0.5. Решения в плане (штабу на утверждение)

1. **Фразы — свой файл `js/захват-знаки.js`** того же вида, что `window.ДеберцЗнаки` (ЭМОЦИИ, ФРАЗЫ,
   БРОСКИ, этоЗнак, этоБросок, предмет, текст, сколько). Комната берёт знаки из поля `знаки` договора
   игры (К12). Почему: в общем файле номера фраз уже живут в партиях деберца, дурака и домино; новые
   строки в нём сдвигали бы или раздували их. Если штаб решит иначе — этап А10 превращается в
   правку общего `js/деберц-знаки.js` с пометкой [Р].
2. **Карта — холст только для стекла.** На холст `drawImage` кладутся готовые рисунки сот, границ,
   стрелок, вспышек (графика.md 4.3). Шайбы с числами, пилюли «+N», имена и метки — слоем узлов
   страницы поверх холста, с классами, а размеры и цвета — в `style-захват.css`. Почему: из js
   нельзя задавать вид (CLAUDE.md), шрифты и цвета живут в CSS, а холст рисует только картинки
   Кодекса.
3. **Маршрут тихой двери — `POST /черновик`** рядом с `case '/ход'` в `server/сервер.js` (около
   строки 1097), проверка входа та же, что у `/ход`. Метод браузера — `Сеть.отправитьЧерновик(раунд,
   черновик)` рядом с `отправитьХод` (`js/сеть.js` около 7354). Имена закрепляются в Б5/Б6.
4. **Страница появляется в корне не раньше, чем решён вопрос с проверкой рейтинга.**
   `tests/у-каждой-игры-рейтинг.js` берёт игры из **всех `*.html` в корне**: как только
   `захват.html` закоммичен, проверка требует запись в `js/игры-реестр.js`, плитку на витрине и
   рейтинг. А коммит = публикация, и плитка недоделанной игры игрокам не нужна. Предлагаю: при
   приёме В1 штаб вписывает «захват» в ДОЛГ этой проверки с причиной «строится, плитки нет до
   сдачи» и вычёркивает строку на этапе С (сдача) — проверка сама напомнит, если забыть. Другой путь —
   держать страницу незакоммиченной до сдачи (плохо: много исполнителей, незакоммиченная работа
   теряется). Решает штаб, тест — общий файл.
5. **Онлайн до О3 без порога 4 раундов** (ТЗ 18, решение штаба по ревью-3) — запись реестра с
   `партияНеКорочеСекунд: 60`, `вес: 0.5`, остальное — на этапе Б11 с Жорой.
