## Ручки сложного по одной (победы сложного: Остров-2 / Материк-4)
| Настройка | Остров-2 | Материк-4 |
|---|---|---|
| как есть | 26 % | 45 % |
| ударовНеБольше 2 / 3 / 4 | 25 / 26 / 26 | 45 / 44 / 45 |
| **поправка: false** | **70 %** | 55 % |
| расстановка: 'лучшая' | 14 | 42 |
| порогСтолицыИКрая 0.7 / 0.75 | 32 / 32 | 43 / 41 |
| лидер: false | 25 | 34 |
| порог 0.75 | 24 | 42 |
| запас: 0 | 32 | 47 |
| столицаОтУгрозы 0.3 / 1.0 | 18 / 27 | 43 / 46 |
| сразу всё (удары 3, поправка выкл., лидер выкл., пороги 0.75) | 58 | 51 |

## Вывод
- Главный виновник — `поправка: true` (поправка на подкрепление защитника): без неё Остров-2 26 → 70 % (П1 проходит), Материк-4 45 → 55 % (П2 нет).
- Предел ударов ничего не меняет (гипотеза Б.1 п.3 не подтвердилась).
- Защита столицы сложному помогает; `лидер: false` вредит (34 % на Материке) — не трогать.
- Порядок для разработчика: поправка: false → запас: 0 (слабый плюс) → Б1, Б2. Материк-4 одними ручками не лечится.
