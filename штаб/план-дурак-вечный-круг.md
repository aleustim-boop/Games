# План: дурак — «вечный круг» кончается победой того, у кого меньше карт

Решение владельца 29.09 22:03: партия пошла по кругу — она кончается, побеждает тот, у кого меньше карт.
Вечный круг — колода пуста, расклад на руках повторяется раз за разом, отбой не растёт, никто не выходит.

## Опись (что есть сейчас)
- **Правила дурака** — `js/game.js`, одни на обе стороны: сервер берёт их через `require('../js/game.js')`
  (`server/партия-по-сети.js:31`, `server/комнаты.js:52`). Отдельного файла `*-правила.js` у дурака нет.
- **Конец подхода** (подход — один заход: карты легли, их отбили или взяли) — `завершитьПодход`, game.js:1380–1427.
  Все пути (пас, «беру», «бито», ход бота) проходят через него: отбой/взятие → добор → выбывшие → ход → `проверитьКонец`.
- **Конец партии** — `проверитьКонец` (game.js:1305): при пустой колоде остался один с картами (в парах — одна пара).
  Итог пишет `записатьИтог` (game.js:1288): `завершена`, `проигравшие` (список дураков), `результат` (имена или 'ничья').
- **Рейтинг**: `учестьИтогПартии` и `застольеДляРейтинга` (server/комнаты.js:2694–2771): «победил» = не в `проигравшие`.
  Ничья для рейтинга — только `партия.ничья === true` (`ничьяВПартии`, комнаты.js:2718, комментарий «у дурака — нет»).
  Очки ничьей в `server/рейтинг.js:184–187` уже есть.
- **Игроку по сети**: `итогДляИгрока` (партия-по-сети.js:429) → `вид.итог` в `видДляИгрока` (партия-по-сети.js:1175).
- **Текст итога**: `текстыИтога` (game.js:6711) и `текстыИтогаКомпании` (game.js:6785). Ничья сейчас объясняется
  только словами «карты кончились у всех разом».
- **Сохранённая партия с ботом** собирается вручную: `собратьЗаписьПартии` (game.js:8003).
- **Автопрогон** `tests/автопрогон-правил-компанией.js`: `отпечатокПоложения` (2136) — руки всех (отсортированы), колода,
  отбой, кто ходит (`атакует` — имя), выбывшие. Снимается в начале подхода, когда стол пуст (2293).
  `ПОВТОРОВ_ДЛЯ_КРУГА = 4` (2151); на четвёртом повторе партия обрывается как «вечный круг» и считается
  отдельно от поломок (2859–2888, печать 3178). Игроки прогона: жадный, случайный, упрямый, пугливый (2813),
  часть ходит `игра.ходБота`. В `tests/автопрогон-правил.js` (вдвоём) круга нет, только потолок в 400 ходов.
- **Боты** (`ходБота`, game.js:1888): «обычный» ходит без случайности, значит, в круге повторяет себя вечно.
  У «лёгкого» (1709, 1776) и «сложного» (1682) есть доля случайности: они могут выйти из круга сами, а могут и нет.
  **Живые игроки** в круг попасть могут: в концовке ходов мало, и человек повторяет очевидное. Выхода в правилах сейчас нет.

## Как будет устроено
**Повтор — только при пустой колоде.** Колода только убывает, отбой только растёт. Поэтому, пока колода не пуста
или отбой вырос / кто-то вышел, старые положения повториться уже не могут: счётчик тогда очищаем, и память не растёт.

**Отпечаток** (строка-описание положения) снимаем в конце `завершитьПодход`, когда стол пуст:
руки всех мест (отсортированы), число карт в отбое (при пустой колоде оно однозначно задаёт отбой), `местоАтаки`
(номер места, не имя: в парах одиночка играет за два места), выбывшие. Колода пуста — в отпечаток не идёт.

**Порог — третье появление одного положения** (как троекратное повторение в шахматах). Почему 3, а не 4, как в прогоне:
в правилах это не догадка «круг вечный», а объявленное правило — игрокам оно знакомо по шахматам, и человек
не досиживает лишний круг (в найденном примере круг — 9 ходов, при пороге 3 это ~20 лишних ходов, при 4 — ~30).
Счётчик кладём в поле партии `повторыПоложений` (объект «отпечаток → сколько раз»).

**Исход** (одна функция `итогПоКругу` в game.js, зовётся из `завершитьПодход`):
- вдвоём: дурак — у кого больше карт;
- трое и больше: дурак — у кого больше всех карт (дурак в игре один, остальные выиграли);
- парами: дураки — пара с большей суммой карт;
- поровну у всех претендентов (вдвоём — поровну; в парах — суммы равны): ничья, `партия.ничья = true`, дурака нет;
  трое+ и поровну только у части самых «тяжёлых» — дураки они все. (Равенство — вопрос владельцу, ниже.)
- ставим `партия.поКругу = true` — по нему экран отличит этот итог от обычного.

**Текст игроку**: заголовок как обычно («Вы выиграли!» / «Вы проиграли» / «Ничья»), пояснение:
«Партия пошла по кругу — расклад повторился трижды. Дурак тот, у кого больше карт: <имя> (<N>)».
Ничья: «Партия пошла по кругу, карт поровну — дурака нет». По сети флаг едет новым полем `вид.поКругу`
в `видДляИгрока` (только там — «клиенту не верим»).

## Этапы
1. **Правило** — developer. Файлы: `js/game.js` (отпечаток, счётчик, `итогПоКругу`, вызов в `завершитьПодход`,
   поле в `создатьПартию` и в `собратьЗаписьПартии`/чтении записи; старая запись без поля → пустой счётчик),
   `tests/дурак-вечный-круг.js` (новый). Проверка: node собирает расклад из прогона (трое, козырь ♦, пустая колода,
   6♣ В♠ / 9♥ 8♣ / 9♠ Д♥) и гоняет `ходБота` «обычный»; требует конца партии на третьем повторе с верным дураком.
   Плюс вдвоём, парами, равенство. Ломающий запуск: `--сломать <путь>` — проверка грузит КОПИЮ game.js из временной
   папки исполнителя, где вызов проверки круга выкинут, и обязана покраснеть. Плюс `node -e "require('../js/game.js')"`
   из server/ и прогон старых автопрогонов.
2. **Сеть и текст** — developer. Файлы: `server/партия-по-сети.js` (`вид.поКругу`), `js/game.js` (тексты итога,
   чтение `вид.поКругу`). Комментарий «у дурака — нет» в комнаты.js — поправить штабу при приёме или отдельной строкой задания.
   Проверка: node-песочница — итог по кругу по сети даёт `итог` и `поКругу` каждому месту; текст содержит «по кругу».
   Ревьюер обязателен (сервер).
3. **Автопрогон** — tester. Файл: `tests/автопрогон-правил-компанией.js`. Детектор на 4 повторах остаётся,
   но теперь это поломка, а не «свойство правил»: если правило не остановило партию к четвёртому повтору — красное.
   Партии, кончившиеся по кругу, считать отдельной строкой (сколько и чем кончились). Ломающий запуск — на копии
   game.js без правила: должно снова найти круги и покраснеть.

## Риски
- **Сеть**: правило живёт в game.js, сервер его подхватит сам — но только после перезапуска боевого сервера (делает штаб).
- **Рейтинг**: ничья по кругу посчитается через уже готовую `ничьяВПартии`; без `партия.ничья = true` строка
  'ничья' ушла бы в рейтинг как победа всех (так уже сейчас при «вышли все разом» — предлагаю проверить отдельно).
- **Сохранённые партии**: поле счётчика не записать — после возврата круг просто досчитается заново (безвредно).
- **Боты**: «лёгкий»/«сложный» иногда сами выходят из круга — тогда счётчик не дойдёт до 3, и это правильно.
- **Злоупотребление**: тот, у кого меньше карт, может тянуть к повтору; сопернику достаточно сыграть иначе один раз.
- **Старый кэш**: старый клиент по сети покажет обычный итог без слов «по кругу» (исход верный). `?v=` у всех страниц
  с game.js поднимает штаб при приёме этапа 2.

## Вопросы владельцу
1. Трое и больше: кто проигрывает? Умолчание — один дурак, у кого больше всех карт, остальные выиграли.
   (Буквально «побеждает тот, у кого меньше» — выиграл бы один, проиграли бы все остальные.)
2. Карт поровну вдвоём / у пар? Умолчание — ничья, дурака нет. Другой вариант — дурак тот, у кого меньше козырей.
3. Трое+ и поровну у двух самых «тяжёлых»? Умолчание — дураки оба.
4. Порог: третье повторение? Умолчание — 3.
