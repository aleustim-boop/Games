# План: лобби дурака — три входа и экран «Играть онлайн»

Составлен 21.09 18:05 по просьбе владельца (запись в очереди «перестройка лобби»).
Решения штаба по спорным местам — в конце файла, владелец меняет любое одним словом.

## Итоговое устройство
Главный экран лобби дурака: три входа — **Играть онлайн**, **Играть с ботами**, **Пригласить друзей**.
«Найти игру» и «Есть код? Войти» с главного экрана уходят.

Экран «Играть онлайн» (сверху вниз): «Найти игру» (автоподбор) → список актуальных столов →
«Создать игру» (заводит комнату и даёт код позвать друга) → тихая строка «Есть код? Войти».

«Пригласить друзей» меняет смысл: это приглашение в САМО ПРИЛОЖЕНИЕ, комнату оно не создаёт.

## Главное решение
Экран «Играть онлайн» — это переделанный существующий `#экран-открытые-столы` (`js/открытые-столы.js`),
а не новый id. В нём уже есть список столов, таймер обновления, посадка за стол, «Назад» и стрелка
Telegram. Заодно не заводим второй список и не рискуем зелёным фоном нового экрана.
`js/сеть.js` план не трогает вовсе: вход по коду и создание комнаты дёргаются нажатием существующих
кнопок (приём `нажатьКнопкуСети` из `js/game.js`).

## Этапы
- **Э1. Три входа** — developer. `index.html` + `tests/проверка-лобби-единый-вид.js`.
  Убрать карточку `лобби-онлайн` (~204) и строку `лобби-код` (~240); у `лобби-друзья` подпись по новому
  смыслу. Проверка сейчас ТРЕБУЕТ `лобби-онлайн` — переписать её тем же этапом.
- **Э2. Приглашение в приложение** — developer. Новый `js/пригласить-в-игру.js` (подключает штаб).
  Ссылка — в ЧАТ бота: `https://t.me/BoardingGames_bot?start=<метка>`, чтобы новичок увидел кнопку
  «Старт»; `bot/бот.js` уже разбирает `?start=` (стр. 190-198). Комнату не создаёт.
- **Э3. Путь дурака** — developer. `js/дурак-путь.js` + `js/game.js`. СТРОГО ПОСЛЕ правки аватара.
  Снять обработчики `лобби-играть-онлайн` и `лобби-код`; `лобби-друзья` больше не зовёт
  `начатьРежим('друзья')`; выставить наружу дверь «создать игру». В `game.js` поправить запасной вход
  (`подключитьЗапаснойВходЛобби`, ~10461), иначе без `дурак-путь.js` «Пригласить друзей» откроет старый
  экран «Игра с другом». Переименовать «Создать комнату» на третьем шаге в «Создать игру».
- **Э4. Экран «Играть онлайн»** — developer + ОБЯЗАТЕЛЬНО reviewer (файл общий с шашками).
  `js/открытые-столы.js`: привязка с `лобби-онлайн` на `лобби-играть-онлайн` (~379); новые кнопки
  рисовать ТОЛЬКО при наличии `#лобби-играть-онлайн`, у шашек экран обязан остаться прежним.
  Коммит общий с Э3: между ними «Играть онлайн» временно мёртв.
- **Э5. Вид** — designer. `style.css`, блок `#экран-открытые-столы` (~13208). Сдача со снимком.
- **Э6. Проверки** — tester. `tests/найти-игру-в-браузере.js` ходит старым маршрутом — переписать.
- **Э7. Приёмка** — reviewer + playtester по опубликованному адресу. `?v=` поднимает штаб у
  `index.html`, `style.css`, `дурак-путь.js`, `game.js`, `открытые-столы.js`.

## Что осиротеет, если не досмотреть
- **«Создать открытый стол»** (`Сеть.создатьОткрытыйСтол`, ~4940) — сегодня единственный способ
  наполнить список, показывается только на пустом списке. Решение штаба: комната из «Создать игру»
  создаётся СРАЗУ ОТКРЫТОЙ, поэтому список наполняется сам, а отдельная кнопка уходит.
- **`#экран-подбор-соперника`** после снятия обработчика достижим только через «Найти игру» внутри
  нового экрана. Не доехал Э4 — недостижимы `js/подбор-экран.js` и очередь `server/подбор.js`.
- **`#экран-друга`** перестаёт быть входом с лобби: остаётся дверью для бед и возврата в партию.
  Согласовать с тем, кто правит `js/сеть.js`.
- **Мёртвые id:** `лобби-онлайн` останется упомянутым в `js/открытые-столы.js` (~379),
  `js/подбор-экран.js` и в проверках; `лобби-код` — в `js/game.js`. Э1 и Э4 обязаны вычистить.

## Решения штаба вместо вопросов владельцу (меняются одним словом)
1. «Найти игру» = автоподбор соперника; список ниже = открытые столы. (Прямо из слов владельца.)
2. Игра из «Создать игру» сразу попадает в список актуальных И даёт код другу. Так список не пустует.
3. Отдельной кнопки «Создать открытый стол» больше нет — она стала не нужна из-за п. 2.
4. «Пригласить друзей» ведёт в ЧАТ бота, а не в мини-приложение: владельцу нужна кнопка «Старт»
   («чтобы его бот видел, нужно чтобы он нажал саму кнопку Старт»).
5. Текст приглашения пишет штаб по словам владельца, показывает ему готовым.
6. Шашки, шахматы и нарды перестраиваем ПОСЛЕ обкатки на дураке.
7. Кнопки «Играть с ботом» на экране столов при молчащем сервере пока не делаем — отдельной задачей.
