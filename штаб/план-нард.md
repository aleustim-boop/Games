# Нарды по набору владельца — опись и план

Опись и план составил разработчик-планировщик 12 сентября (13:49–13:58) по набору `эталон/нарды-набор/`. Владелец в 13:48 ответил: «Всё по макету, сколько бы ни заняло». Штаб утвердил порядок этапов 12 сентября.

## Опись: что есть сейчас

- `нарды.html` — 7 экранов; `js/нарды-правила.js` (1630 строк, самопроверка мутантами: `node js/нарды-правила.js`); `js/нарды-бот.js` (**два** честных уровня — третий убран после турнира на 2000 партий, давал 50/51%); `js/нарды-экран.js` (1178 строк, доска из CSS-треугольников, узел шашки живёт всю партию); `style-нарды.css`.
- **Совпадает с макетом уже сейчас:** 24 пункта, бар, полки выноса, кубики с прокруткой броска, подсветка допустимых пунктов и выбранной шашки, «Вернуть шаг» (по одному перемещению), «Передать ход», три вида доски, «Как играть».
- **Нет вовсе:** звука, сети, рейтинга на экране, нижних вкладок, панелей игроков, таймеров, чата, лобби по макету. Вид старый: зелёное сукно и синие кнопки, тогда как общий `style.css` уже на новом стандарте (акцент салатовый).

### Ключевые факты, которые меняют оценку
- **Правила нард уже написаны под сервер:** `бросить(партия, кубики)` — кубики снаружи; `сделатьХод(партия, ход)` — ход целиком, «не получилось — null, доска не тронута»; `найтиХод(партия, запись)` — сервер проверяет присланный ход, а не верит ему.
- **Договор сервера** — `server/игры/реестр.js` (7 функций), живой образец `server/игры/шашки.js` (584 строки), мост-образец `js/шашки-сеть.js` (180 строк).
- **Рейтинг нард заведётся сам:** `таблицаИгры()` открывает таблицу по имени, `нарды: { вес: 0.3 }` в `server/игры/умолчания.js` уже есть. Билеты за игру с ботом выдаются только дураку (`server/билеты.js`), поэтому подпись макета «Тренировка не влияет на рейтинг» для нард сегодня — правда.
- **Чат уже есть в виде готовых фраз:** `js/шашки-знаки.js` (8 смайликов, 10 фраз, 15 бросков), по сети едет только номер, сервер проверяет его, бот отвечает сам.
- **Нижняя полоса уже есть** в общем `style.css` (`.нижние-вкладки`) — на витрине и в лобби дурака; у нард её просто нет на странице.
- **Список знакомых есть:** `server/знакомые.js`, дверь `POST /знакомые`, проверки в tests/; дурак уже рисует такой список. «Друзья» — не с нуля.
- `js/сеть.js` не знает слова «нарды» (`МЕТКИ_ИГР`) — без метки ссылка-приглашение уведёт в карты.

## Этапы

**Э1. Лобби нард по макету** — разработчик 6–10 ч, оформитель 3–5 ч, тестировщик 1–2 ч, сервер не трогаем.
`нарды.html`, новый `js/нарды-лобби.js`, `style.css` (оформитель), `img/нарды/`. Шапка и «⋯», «Нарды» + «Правила» (закрывает старую претензию «правила только внутри партии»), баннер рейтинга, режимы, вариант, сложность, главная кнопка, таблица лидеров, нижние вкладки.

**Э2. Стол нард по макету** — разработчик 10–16 ч, оформитель 4–6 ч, тестировщик 2 ч.
`js/нарды-экран.js`, `style-нарды.css`, `нарды.html`, `img/нарды/`. Доска — `board-empty.png` одной картинкой, фишки и кольца отдельными слоями по процентам из `integration/board-geometry.json`, кубики — SVG 1–6, панели игроков, «Ваш ход», подсказка. Отдельным шагом: «Отменить ход» (весь ход разом) и «Подтвердить». Таймеры не рисуем.

**Э3. Нарды по сети** — разработчик 10–14 ч, тестировщик 2–3 ч, **перезапуск сервера**.
Новый `server/игры/нарды.js`, строка в `server/игры/реестр.js`, новый `js/нарды-сеть.js`, метка в `js/сеть.js`, `нарды.html`. Кубики бросает сервер, ход уходит целиком после «Подтвердить», вид собирается вручную полем за полем. Включаются сами: рейтинговые матчи, рейтинг нард, знакомства, приглашения, реванш.

**Э4. Чат готовыми фразами** — разработчик 4–6 ч. Новый `js/нарды-знаки.js`, `js/нарды-экран.js`, `server/игры/нарды.js`, оформление в общий `style.css`.

**Э5. Время на ход** — разработчик 8–12 ч, тестировщик 2–3 ч, **перезапуск сервера**. `server/комнаты.js` (3042 строки — самая мутная оценка), `server/игры/реестр.js` (новое поле договора «что делает игра, когда время вышло»), браузер. Защита: срок хода — необязательная настройка комнаты, по умолчанию выключена, тогда дурак и шашки не меняются ни на строчку.

**Э6. Вкладка «Друзья» — СНЯТА 12 сентября в 15:13.** Владелец выбрал подписи полосы «Лобби · Рейтинг · Профиль», вкладки «Друзья» там нет. Дверь `/знакомые` и список знакомых внутри «Играть с другом» остаются как есть; отдельный экран друзей вернётся, только если владелец попросит.

## Честное «скоро», пока этапы не сделаны
- «Онлайн · Рейтинговые матчи» до Э3 — карточка выключена с пометкой «скоро» (класс `.пометка-скоро`).
- Кнопка «Чат» до Э4 — не рисуем вовсе: в партии с ботом она бессмысленна.
- Таймеры до Э5 — пилюли не рисуем: пустое «--:--» выглядит поломкой. В панели игрока имя и «В сети».
- Пустой рейтинг нард — «Здесь пока никто не играл» + «рейтинг появится после первой партии онлайн».

## Опасные места
1. `style.css` (12 845 строк) общий — правит только оформитель. Разработчик из кода задаёт лишь данные (номер пункта, слой).
2. `js/сеть.js` (4767 строк) общий с дураком и шашками — нужна одна строка метки; после правки прогнать сетевые проверки **всех** игр.
3. `js/нарды-правила.js` с Э3 становится общим с сервером: правка меняет обе стороны, после каждой — `node js/нарды-правила.js`.
4. `server/комнаты.js` опасен только на Э5; защита — настройка по умолчанию выключена.
5. Геометрия доски — это вид: проценты из `board-geometry.json` кладём переменными в файл оформителя, из кода — только номер пункта. Иначе повторится история с панелью знаков в шашках.
6. Новые файлы (`js/нарды-лобби.js`, `js/нарды-сеть.js`, `js/нарды-знаки.js`) подключает штаб тем же коммитом, которым принимает работу.

## Решения штаба (12 сентября)
- **Лобби нард делаем по его макету**, а не через три шага дурака: владелец сказал «всё по макету». Единство держим общими классами.
- **В проект копируем только рабочие ресурсы** (~1,9 МБ) в `img/нарды/`; `references/` и `docs/` остаются в `эталон/нарды-набор/`.
- **Порядок изменён против плана: сначала Э2 (стол), потом Э1 (лобби)** — лобби упирается в вопросы владельцу (названия вариантов, число уровней бота, подписи вкладок), а стол от них не зависит.
- **Подписи нижней полосы** — «Игры · Друзья · Профиль», из последнего набора; уточняющий вопрос владельцу задан.
- Мост в сеть — копией устройства `js/шашки-сеть.js`; кубики в сетевой партии бросает сервер; ход уходит одним куском после «Подтвердить».
