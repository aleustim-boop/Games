### Бот за ушедшего: общий механизм уже есть

Живёт целиком в `server/комнаты.js` (`выйти` и `вернутьЗаСтол`), работает для любой игры из реестра. Для деберца и домино уже включается при выходе и при молчании; серверные боты обеих игр ходят с любого места (`деберц.js:47-59`, `домино.js:35-39`; в фазе «итог» бот домино сам жмёт «раунд»). Не хватает трёх вещей:

- сдача не должна кончать партию у всех;
- вернуться нельзя тому, кто вышел сам (пропуск стирается, `местоПоТелеграму` его пропускает, `:790`);
- нет своего времени на ход.

Страница после «В меню» забывает комнату: `забытьКомнату` (`js/сеть.js:4109`). А проверка «партия жива» опрашивает `/состояние` по пропуску (`:4029`), и такой опрос сам сажает игрока обратно. Значит, для возврата нужна отдельная дверь, а не старый пропуск.

### Рейтинг

- Пишется только по доигранной партии: в поле «результат» должна быть строка (`комнаты.js:2752-2773`).
- Ушедший в учёте — человек и проигравший (`:2803-2831`): `этоБот` выключается пометками «сдался» / «вышел победителем».
- Вернувшийся посреди партии теряет пометку «сдался» (`:1966`), в рейтинг идёт его настоящий итог.
- Последний человек ушёл — сдавшиеся всё равно получают поражение (`закрытьСдачейУшедших` `:4485`).
- В `server/рейтинг.js:1002` очки за победу даются только за соперников, кончивших хуже. «Все оставшиеся победили» дают очки только за ушедших.

## Как голосуют

- Предложить может любой человек, сидящий за столом сам. Его голос сразу «за».
- Голосуют только люди, сидящие сами. Боты не голосуют (иначе один человек с двумя ботами решал бы за стол). Ушедшие не голосуют; вернувшись — голосуют снова.
- Кто на время потерял связь, остаётся в подсчёте: молчание считается «нет».
- Порог — округление вверх от 70% живых людей: из 2 нужно 2, из 3 — 3, из 4 — 3, из 5 — 4, из 6 — 5.
- Человек за столом остался один — партия кончается сразу (как сегодня выход против одних ботов).
- Пока идёт голосование, партия не встаёт на паузу. Все видят одну плашку, у голосующих на ней две кнопки.

## Риски

- **Утечка руки (этап 4).** Возврат не должен идти через `/состояние`: сегодня проверка «партия жива» по старому пропуску сажала бы игрока обратно молча. Ревьюеру проверить, что `пропускВозврата` не находит `местоПоПропуску`.
- **Ничья у деберца (этап 3).** После прерванной партии деберц показывает «ничья» (`деберц.js:100`). Монополия признака «прервана» не знает — экран может застрять.
- **Катан (этап 5).** Правка в `комнаты.js` меняет его поведение, это чужая зона. Нужно согласие другой сессии.
- **Сговор трёх против четвёртого, который выигрывает.** Защита — умолчание вопроса 2: у согласных нет выгоды, рейтинга нет.
- **Проигравший при согласии.** `осмотретьПартию` берёт `проигравшие[0]` как дурака прошлой партии. При согласии без ушедших список пуст — нормально, первым ходит младший козырь.
- **Пометка «спит» (этап 11б).** Место с `этоБот=true` без ухода рейтинг сочтёт ботом (`комнаты.js:2814`), если не добавить исключение. `найтиИгрока` не должен снимать «спит» простым опросом.
- **Поле вне списка.** `досрочно` подкладывается мимо `видДляИгрока` (как `аватары`), страж полей его не увидит. Проверка этапа 3 обязана сверять точный список ключей.
