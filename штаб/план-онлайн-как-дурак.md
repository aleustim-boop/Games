## 0. Главное открытие (коротко)

Бо́льшая часть онлайна дурака **уже общая**, в js/game.js её почти нет:
экран «Играть онлайн» (js/открытые-столы.js), «Найти игру» (js/подбор-экран.js), комната-05 с местами, ботами и «Позвать знакомого» (js/дурак-комната.js), связь, коды, ссылки, возврат (js/сеть.js), рейтинг (server/комнаты.js:2647 `рейтинг.учестьПартию(комната.игра, …)` — для любой игры).

Почему в нардах «только код». Комната-05 рисуется только для стола-«компании»: js/сеть.js:1603 `компания = Array.isArray(вид.застолом)`, а «застолом/яХозяин/можноНачать» сервер кладёт только при `комната.компания` (server/комнаты.js:2062–2075). ## 3. Главное решение: не делать работу 7 раз

**Не выносить заново то, что уже общее.** Общими уже являются открытые-столы.js, подбор-экран.js, дурак-комната.js, сеть.js, друзья-экран.js, деберц-сказать.js. Не хватает одного: **одного места, где игра говорит «я сетевая, вот мои места и настройки»**, и которое само ставит на страницу всё остальное. Сейчас это знание размазано: ветки по имени игры в сеть.js `телоСоздания`, списки ИГРЫ_С_ПОДБОРОМ в двух файлах, скопированная в 5 страниц разметка комнаты-05, js/деберц-онлайн.js для четырёх чужих игр.

### Новый модуль js/онлайн-лобби.js

Игра зовёт один раз, при загрузке своего лобби:
```
ОнлайнЛобби.подключить({
  игра: 'нарды',                     // ключ, как в js/игры-реестр.js
  мест: { мин: 2, макс: 2, обычно: 2 },
  настройкиСтола: () => ({ … }),     // только данные: цель, вариант, пары; проверяет сервер
  создание: 'сразу' | 'экран-друга', // сразу — стол на двоих без шагов; экран-друга — своя страница настроек
  знаки: () => контекстСтола | null  // есть — ставим общую панель эмоций
})
```
Модуль делает сам (ничего из этого игра не пишет):
1. Ставит разметку комнаты-05 в `#экран-комнаты`, если на странице её нет (шаблон — из index.html; дальше страницы свою копию не держат).
2. Переносит `#кнопка-вернуться-в-игру` в лобби первым узлом (как у дурака) или создаёт её там.
3. «Создать игру» → `Сеть.создатьКомнату({ мест, компанией: true, открытый: true, …настройкиСтола() })` — стол сразу «компания», значит комната-05 с местами, ссылкой, «Позвать знакомого», ботом.
4. Подключает панель знаков (js/деберц-сказать.js + деберц-знаки.js), если игра дала `знаки`.
5. Отдаёт `ОнлайнЛобби.описание(игра)` — для сеть.js (тело создания) и открытые-столы.js (показывать ли «Найти игру») вместо своих списков.

Отдаёт игре — ничего нового: стол по-прежнему приходит через `ИграПоСети.показатьВид` из сеть.js.

### Договоры
- **js/сеть.js остаётся единственной дверью к серверу.** Модуль сам запросов не шлёт — только зовёт `window.Сеть.*`. В сеть.js `телоСоздания` берёт настройки у `ОнлайнЛобби.описание()`; ветки по именам игр уезжают туда по мере переезда игр (не раздваиваем: переехала игра — её ветку из сеть.js убираем тем же этапом).
- **Клиенту не верим.** Число мест и настройки — только просьба; пределы проверяет server/комнаты.js (`пределыМест`). Поля комнаты-05 (`застолом`, `яХозяин`, `можноНачать`, знак, «ещё») наружу собирает `видДляИгрока` каждой игры в server/игры/*.js поле за полем.
- **Один файл — один исполнитель**: этапы ниже разнесены так, что общие файлы трогаются по одному за раз.
- Оформление: из js — только классы и `--мест`. Вид комнаты-05 уже есть в style.css (`.рассадка--комната`); если на страницах со своим оформлением (style-нарды.css и т.п.) поедет — это отдельный этап оформителя, не разработчика.
