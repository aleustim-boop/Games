# План: стол шашек по набору владельца (15 сентября)

Владелец прислал набор `checkers_telegram_miniapp_assets_v1` (рабочие картинки — `img/шашки/`, инструкции и макеты — `эталон/шашки-набор/`) и два макета: лобби и стол. Эталон стола — `эталон/шашки-набор/стол-эталон-941x1671.png`, лобби — `лобби-эталон-941x1672.png`, цвета и геометрия — `layout_tokens.json` (акцент #D4FF4F, дерево #D8A66D/#4A2A18, клетки 99×98, шашки 384×384 — чёрная и слоновая кость).

Набор повторяет шахматный, поэтому и путь тот же, что у стола шахмат (`штаб/план-шахматы-стол.md`, Э1–Э3 закрыты 15.09): те же слои, те же решения, те же проверки по образцу.

Жёсткие правила набора (совпадают с нашими): тексты, кнопки, таймеры — только DOM; шашки масштабирует браузер (картинки 384 не увеличивать заранее); **дамка — не отдельная картинка, а SVG-корона поверх обычной шашки**; позиция — из движка, макет — только сверка вида; `references/` в публикацию не тащить; имена файлов — латиницей. Доска: a1 тёмная, светлые снизу, шашки только на тёмных клетках.

Что у шашек уже есть (не переделывать): лобби на общем каркасе с тремя входами и нижней полосой, три уровня бота, игра по сети по коду, «Как играть», звук, серия побед, знаки внимания в сетевой партии.
