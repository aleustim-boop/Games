## 2. Что не делаем и почему

**Бот или аккаунт, который ходит по чужим группам и зовёт людей, — не делаем.**

- Правила Telegram прямо называют спамом непрошеные сообщения незнакомым людям с рекламой и ссылками, а также добавление людей в группы без согласия. [источник: telegram.org/faq_spam]
- Аккаунт за это ограничивают: сначала на несколько дней, потом дольше, вплоть до постоянного. [источник]
- Правила для разработчиков ботов (п. 5.2, разд. 10) допускают бан бота и аккаунта владельца. Потерять @BoardingGames_bot значит потерять всех игроков и все разосланные ссылки. [источник: telegram.org/tos/bot-developers]

**Граница для всего плана:** бот пишет только тем, кто сам нажал Start или сам добавил его в чат. Незнакомым людям пишет только живой человек, от себя, там, где это разрешено правилами чата.

### 0.3. Дыры в учёте

### 0.4. Холодный старт: новичку не с кем играть
- Если в подборе никого нет, игрок ждёт бесконечно или сам жмёт «Играть с ботом» (`server/подбор.js:6-12`, решение владельца от 30.09). [код]

  - «час игры»: объявленное время (например, каждый вечер в 20:00 по Киеву/Москве), когда все приходят одновременно.
- Нужно решение владельца, какой вариант брать.

6. **Мост в Telegram.** На сайте кнопка «Открыть в Telegram» с меткой `src_site` — там игрок получает рейтинг, друзей и письма от бота.

Вопрос владельцу: адреса файлов кириллические (`монополия.html`). Поисковики их понимают, но ссылки при пересылке превращаются в длинный набор `%D0%BC…`. Возможны латинские адреса-двойники (`/durak`, `/monopoly`) через nginx без переименования файлов.

Ожидание: поисковый трафик растёт медленно, месяцы. Конкуренция по «дурак онлайн» высокая; реальнее брать длинные запросы: «с другом по ссылке», «без регистрации», «в телеграме».

## 9. Этап 6. Посев руками

Делает владелец со своего аккаунта. Автоматизации нет.

1. Найти чаты и каналы про настольные игры, компании друзей, локальные сообщества. Готового списка чатов с разрешённой саморекламой найти не удалось [не подтверждено] — в каждом читать закреплённые правила.
2. Писать админу: предложить бота чату как развлечение (добавить бота, играть командой `/играть`), а не просить рекламу. Для админа это польза его чату.
3. Взаимный пиар с небольшими каналами (до 5 тыс. подписчиков): мы упоминаем их в канале проекта, они нас.
4. Свой канал проекта: новости игр, итоги «Раздачи дня», объявления «часа игры». Ссылку на канал поставить в бота и в игру.
5. Личный круг: добавить бота во все свои чаты с друзьями и роднёй, сыграть там. Первые 50–100 игроков почти всегда приходят так.

Возможный инструмент на потом: программа, которая читает открытые чаты по словам «во что поиграть», «кто в дурака» и присылает владельцу ссылку на сообщение. Отвечает человек, сам и по одному. Автоответов не делать.

## 10. Этап 7. Рефералы, турниры, сторис

Делать после того, как появятся первые живые игроки: вирусные механики умножают поток, а не создают его.

1. **Номер пригласившего в ссылке.** Сейчас в `?start=invite_<метка>` его нет (`server/сервер.js:1762`, `:1777`). Добавить, считать «кто кого привёл».
2. **Награда за друга — обеим сторонам.** Денег в игре нет, поэтому награда — оформление: рубашка карт, рамка аватара, значок «привёл 5 друзей». Засчитывать, только когда друг доиграл партию, иначе накрутят.
3. **Победа в сторис.** Метод `shareToStory` (Bot API 7.8) — картинка победы со ссылкой на игру. [источник]
4. **Статус победителя.** `setEmojiStatus` (Bot API 8.0) — эмодзи-статус победителю турнира. [источник]
5. **Ярлык на рабочий стол.** `addToHomeScreen` (Bot API 8.0) — предложить после третьей партии. [источник]
6. **«Похвастаться» для всех игр.** Сейчас метки заданы только для 5 игр (`js/похвастаться.js:55`). [код]
7. **Еженедельный турнир.** Таблица недели по каждой игре, итог в воскресенье письмом от бота тем, кто играл, и в канал проекта.
8. **Возврат ушедших.** Писем «давно не заходили» нет. [код] Одно письмо через 3 дня и одно через 14, с кнопкой отказа (механизм отказов уже есть в `server/не-звать.js`). Не чаще — правила допускают только добросовестные рассылки. [источник]

Урок чужого опыта: Hamster Kombat потерял около 95% аудитории, когда кроме наград ничего не осталось. Награда должна подталкивать к игре, а не заменять её.

## 11. Этап 8. Яндекс Игры и VK Игры

Самый большой возможный поток и самая большая работа. Начинать только после решения владельца.

**Яндекс Игры** [источник: yandex.ru/dev/games, требования от 29.09.2026]:
- Обязателен SDK Яндекса; вход только через Яндекс ID по кнопке, обязателен гостевой режим.
- Архив zip с `index.html` в корне, до 100 МБ, **без кириллицы и пробелов в именах файлов и папок**.
- Внешние ссылки запрещены — ссылку на бота поставить нельзя. Это отдельная аудитория, в Telegram она не перейдёт.
- Свой сервер разрешён: адрес заявляется в консоли, только https/wss и домен.
- Публикация бесплатная, модерация 3–5 рабочих дней.

Что это значит для проекта [код]:
- Кириллица в именах: 15 из 29 html, 100 из 132 js, 26 из 34 css, 512 из 575 картинок. Нужна программа сборки, которая делает латинскую копию и правит все ссылки. Исходники не переименовывать.
- Скрипт Telegram подключён на всех 25 страницах, обращения к Telegram — в 14 js-файлах. Удобная точка подмены — `js/telegram.js` (договор `isReady`, `saveScore`, `loadScore`).
- Главное препятствие — вход на сервере: личность проверяется только подписью Telegram (`server/сервер.js:1429`). Нужна вторая проверка — по подписи Яндекса.
- Внешних загрузок, кроме скрипта Telegram, нет — это плюс.

Открытые вопросы:
- **Страна владельца.** Нерезиденты России регистрируются через Рекламную сеть Яндекса; доступность из Украины не подтверждена, сервисы Яндекса там заблокированы. [не подтверждено] Проверить первым — если нельзя, этап закрыт.
- **Сборник или отдельные игры.** Правила не найдено. Отдельные игры дают больше точек входа в каталог. Начать с одной — дурака — как пробы.

**VK Игры** [источник: dev.vk.ru/en/games-catalog-rules]: HTTPS, мобильная вёрстка, русский язык, политика приватности, не менее 10 минут игры, запрет уводить людей за пределы VK, подключение VK Bridge. Доступность для физлиц и нерезидентов не подтверждена.

**Международные порталы** (CrazyGames, Poki, GameDistribution): свой SDK у каждого, аудитория нерусскоязычная — не приоритет.

Порядок, если решение «да»: проверка регистрации → сборка латинской копии → прослойка площадки вместо `js/telegram.js` → дурак с ботом без сети → модерация → сеть и остальные игры.

## 12. Как измерять

Смотреть раз в неделю, из `/статистика` и отчёта сервера:

| Показатель | Зачем |
|---|---|
| Новые игроки по источникам | Какой канал работает |
| Доля новых, сыгравших хотя бы одну партию | Понятен ли вход |
| Вернулись на следующий день и через неделю | Держит ли игра |
| Число групп с ботом и столов из групп | Работает ли этап 1 |
| Приглашения: отправлено → друг сел → доиграли | Работает ли вирусность |
| Партий с людьми и с ботом | Хватает ли живых соперников |
| Время ожидания в подборе | Острота холодного старта |

Правило: канал, не давший за месяц ни одного сыгравшего игрока, отключаем и силы переносим туда, где есть отдача.

## 14. Решения, которые нужны от владельца

1. Холодный старт (п. 0.4): счётчик онлайна, «позовите, когда найдётся соперник», «час игры» — что из этого берём.

3. Латинские адреса-двойники страниц на сайте.
4. Рейтинг для гостей из браузера: давать или только через Telegram.
