# План: шахматы онлайн

Опись и план — 29.09 (исполнитель, только чтение, кода нет).
Слова владельца: «Почему до сих пор шахматы не могу играть онлайн? Нужно это реализовать в первую очередь».
Поправка штаба: эталон онлайна — **дурак** (вход в онлайн, открытые столы, «Ищем соперника», друг по коду, «Позвать», «Вернуться к игре», рейтинг). Шашки — только образец «доски на двоих» на сервере и моста доска↔сеть.

## 1. Опись: что есть и что берём

**Правила и бот годятся для сервера как есть.** Проверено командой: `require('js/шахматы-правила.js')` и `require('js/шахматы-бот.js')` в node грузятся без ошибок, window/document на верхнем уровне нет (выход — `module.exports` + `window.ШахматыПравила`).
- Правила наружу: `создатьПартию, партияИзFEN, fenПартии, картинкаПартии, копияПартии, чейХод, подШахом, возможныеХоды, ходыФигуры, сделатьХод({откуда,куда,превращение?}), партияЗавершена, завершитьСПричиной(партия, результат, причина), итог → {победитель, ничья, причина}, запись, отпечатокПозиции`. Внутренний `найтиХод` без `превращения` на ходе-превращении даёт null — ход не делается (правильно: выбор за игроком).
- Счётчики партии: `полуходов`, `безВзятийИПешек`, `былиПозиции` (троекратное повторение), `наПроходе`, `рокировка` — всё внутри объекта партии, живёт на сервере.
- Бот: `УРОВНИ` (0/1/2), `УРОВЕНЬ_ПО_УМОЛЧАНИЮ = 'обычный'`, `выбратьХодСразу(партия, {уровень, бюджетМс})` — как у шашек.
- `js/шахматы-звук.js` в node НЕ грузится (document на верхнем уровне) — серверу он и не нужен, не require'ить.
- **Внимание:** `партияИзКартинки` теряет права рокировки, поле «на проходе» и счётчики. Клиенту слать **FEN** (`fenПартии`), а не только картинку.

**Сервер (образец — server/игры/шашки.js, 625 строк).** Договор игры — server/игры/реестр.js: `имя, мест, раздать, чейХод, видДляИгрока, сделатьХод, ходЗаБота, темпБота, ходВнеОчереди, напарник, знаки, текстСобытия`. У шашек там же: ничья по соглашению (`ничья`/`ничья-да`/`ничья-нет`, пауза 6 полуходов после отказа), сдача (`сдаться` — по `цвета[ктоЯ]`, не по очереди), `последнийХод`, `итог`, знаки внимания (`js/шашки-знаки.js`). Всё переносится почти дословно.
- Рейтинг: комнаты зовут `рейтинг.учестьПартию(комната.игра, …)` (server/комнаты.js `учестьИтогПартии`) — общий путь по имени игры, вес шахмат уже есть (`вес: 1` в js/игры-реестр.js). Нужно только, чтобы комната с игрой «шахматы» существовала.
- Часы: у шашек по сети часов **нет** (шашки-экран.js: «по сети контроль всегда нет»). Но у комнат есть готовые крючки для игры — `игра.остатокВремениНаХод(партия)` и `игра.ходПоПросрочке(партия)` (server/комнаты.js `завестиТаймерПросрочки`/`сработалаПросрочка`); ими уже пользуется катан (server/игры/катан.js стр. 54–55). Шахматные часы Фишера ложатся на них без правки комнат.
- Настройки стола (контроль времени) до игры доходят так же, как `катанНастройки`: клиент кладёт в `телоСоздания` (js/сеть.js ~3290), комната сохраняет (server/комнаты.js ~1128), `раздать(ктоНачинает, настройки)`.
- Выход соперника, пропажа связи (3/5 минут), «больше не играет», возврат после перезапуска, реванш («ещё»), открытый стол — общие, живут в server/комнаты.js и js/сеть.js, от игры не зависят.
- Подбор: server/сервер.js `ИГРЫ_ПОДБОРА` и `УРОВЕНЬ_БОТА_ОТ_ПОДБОРА` (~2949) — шахмат нет.
- Названия/ссылки: server/названия.js — строка шахмат есть, но `метка: null` («по сети не играются»). Латинское имя уже выбрано — `shahmaty` (js/telegram.js `ЛАТИНСКОЕ_ИМЯ_ИГРЫ`).

**Браузер.** Эталон дурака, как его уже повторили шашки и нарды:
- js/сеть.js — общий: игра страницы из `window.ИграСтраницы`; коды, приглашения, «Вернуться к игре с другом» (`кнопка-вернуться-в-игру`, ключ комнаты `<игра>:комната`), друзья/«Позвать», знаки, реванш, открытые столы, подбор. Шахмат не знает: `МЕТКИ_ИГР` (стр. 156), `ВО_ЧТО_ИГРАЕМ` (стр. 4247) — нет строки шахмат; `НАЗВАНИЯ_ИГР` (5073) — есть.
- js/открытые-столы.js — экран «Играть онлайн» дурака (открытые столы, «Найти игру», «Создать игру», «Есть код?»), открывается узлом `лобби-найти-игру`; `ИГРЫ_С_ПОДБОРОМ` (стр. 63) — шахмат нет.
- js/подбор-экран.js — «Ищем соперника», общий.
- js/похвастаться.js `МЕТКИ_ИГР` (стр. 55) — шахмат нет.
- Мост доска↔сеть: образец js/шашки-сеть.js (196 строк): `window.ИграПоСети = {начать, показатьВид, показатьСвязь, экран, вМеню, назадСоВхода, идёт}` + перевод имён экранов.
- js/шахматы-экран.js (2158 строк): соперник только «человек»/«бот», **публичной двери наружу нет** вовсе. Часы, ничья (`предложитьНичью`), сдача (`сдатьсяПодтверждённо`), превращение (`экран-превращения`) — локальные. Нужен сетевой режим как у шашек: `включитьСеть(отправитель)`, `выключитьСеть()`, `показатьСетевойВид(вид)` и наружу `window.ШахматыЭкран`.
- js/шахматы-лобби.js: карточка «Играть онлайн» — `лобби-играть-онлайн`, в разметке `disabled`. У шашек/нард узел называется `лобби-найти-игру`, его сам находит js/открытые-столы.js.
- шахматы.html: нет `window.ИграСтраницы`, нет js/сеть.js, моста, открытые-столы.js, подбор-экран.js, экранов `экран-друга/экран-комнаты/экран-входа`, `строка-связи`, ленты. Образец — шашки.html стр. 544–643, 731, 896–905.
- Рейтинг: js/игры-реестр.js — у шахмат `способОчков: []`; tests/у-каждой-игры-рейтинг.js держит шахматы в `ДОЛГ` (стр. 71).

## 2. Этапы (по порядку)

Общие файлы помечены **[ОБЩИЙ]** — после их правки обязателен ревьюер (полная модель).

**Э1. Сервер: игра «шахматы» — server/игры/шахматы.js (новый файл).**
Копия устройства server/игры/шашки.js на шахматных правилах: `раздать` (белые — названный начинающим, иначе первое место), `сделатьХод` (действие `ход` → поля `откуда, куда, превращение` поимённо, превращение — только из белого списка правил; проверка очереди; ход берём из `Правила.возможныеХоды` — одним `сделатьХод` правил), ничья по соглашению и сдача — перенос шашечных функций, итог через `Правила.итог`/`завершитьСПричиной`; `ходЗаБота` на `js/шахматы-бот.js` с бюджетом 150 мс; `видДляИгрока` поле за полем: `fen`, `доска` (картинка), `чейХод`, `мойЦвет`, `яХожу`, `шах`, `последнийХод {откуда, куда, запись, чей(цвет), мой}`, `итог`, ничья, служебные поля комнаты (как у шашек, без `застолом` у стола на двоих); `текстСобытия` без глаголов прошедшего времени; знаки — пока через js/шашки-знаки.js или без знаков (вопрос 3). Часов в Э1 нет.
Проверка: `tests/шахматы-сервер-правила.js` (node, без сервера): раздать → вид белых/чёрных; ход не в очередь — отказ; незаконный ход — отказ словами; ход-превращение без фигуры — отказ «выберите фигуру», с фигурой — принят; рокировка O-O и взятие на проходе проходят через `сделатьХод` и видны в FEN; мат «детский» → `завершена`, `результат`, `проигравшие`; троекратное повторение конями → ничья; ничья по соглашению и сдача; `ходЗаБота` даёт законный ход; в `видДляИгрока` нет ключей кроме белого списка (сторож полей, как tests/сторож-полей.js). Ломающий запуск: копия файла во временной папке, где (а) вид отдаёт `партия` целиком — краснеет сторож полей; (б) сдаётся тот, чей ход, — краснеет сдача; (в) превращение по умолчанию ферзь — краснеет превращение.

**Э2. Сервер: включить игру — server/игры/реестр.js [ОБЩИЙ] + server/названия.js.**
Строка `шахматы` в `ИГРЫ` реестра; в названиях `метка: 'shahmaty'` и убрать комментарий «по сети не играются». Проверка: `node -e "require('./server/игры/реестр.js')"` из папки server/; `tests/шахматы-комната.js` — тестовый сервер на своём порту (не 8790, `--без-памяти`): создать комнату `игра: 'шахматы'`, второй входит по коду → этап «игра», ходы обоих, выход второго → первому победа, рейтинг учёл партию (файл рейтинга тестовой копии). Прогнать старые tests/маршрут-приглашения-8-игр.js, tests/онлайн-сервер.js. Ломающий: копия server/ без строки в реестре → создание комнаты отказ → краснеет.

**Э3. Экран: сетевой режим доски — js/шахматы-экран.js.**
По образцу шашки-экран.js: `соперник = 'сеть'`, `включитьСеть(отправитель)`, `выключитьСеть()`, `показатьСетевойВид(вид)` (позиция из `вид.fen` через `партияИзFEN`, свой цвет снизу — доска переворачивается для чёрных; конец партии — только из `вид.итог`, сам не решает), ход — через отправителя, при отказе вернуть фигуру и показать причину; превращение — окно выбора, потом отправка с `превращение`; «Сдаться» и «Ничья» по сети — `window.Сеть.отправитьХод({действие:'сдаться'|'ничья'|'ничья-да'|'ничья-нет'})`; реванш «ещё»; часы в сети скрыты (до Э8); наружу `window.ШахматыЭкран = {включитьСеть, выключитьСеть, показатьСетевойВид, показатьПоИмени}`. Ломающий: копия, где позиция берётся из `вид.доска` через `партияИзКартинки` — рокировка после неё пропадает, краснеет.

## 3. Риски

- **Превращение по сети.** Без `превращение` ход неоднозначен и правилами отвергается — клиент обязан спросить фигуру ДО отправки. Сервер берёт только из белого списка значений правил.
- **Рокировка / на проходе.** Клиент, собирающий позицию из картинки, покажет рокировку невозможной — только FEN (закрыто в Э1/Э3 проверкой).
- **Троекратное повторение** считается по `былиПозиции` — есть только на сервере; клиент ничью сам не объявляет, берёт `итог`.
- **Время.** До Э8 партия по сети без часов: соперник может «пересидеть». Страховка есть — пропажа связи 3/5 минут и сдача. Часы на сервере, не на телефоне (иначе клиенту верим).
- **Бот на сервере.** Перебор синхронный — бюджет 150 мс, как у шашек; на слабой машине тормозит все столы. Замер в Э1.
- **Порядок выкладки.** Новый клиент на старом сервере (игры «шахматы» нет) — отказ при создании. Сперва сервер (Э1–Э2, перезапуск штабом), потом страница.
- **Общие файлы** (реестр, сеть.js, открытые-столы.js, сервер.js, комнаты.js) — правят другие исполнители; каждому этапу — свой исполнитель, штаб раздаёт файлы вслух.
- js/шахматы-экран.js большой (2158 строк) — Э3 самый долгий; если не влезает в пару часов, делить: Э3а вид из сети + отправка хода, Э3б ничья/сдача/реванш.

## 4. Вопросы владельцу

1. Часы по сети в первой версии нужны, или сначала «без часов» (как шашки), а часы — следом (Э8)? Предлагаю: сначала без часов — быстрее доедет до игроков.
