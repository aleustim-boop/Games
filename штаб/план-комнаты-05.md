## Решения планировщика, принятые штабом
- «‹» на комнате = «Выйти из комнаты» без подтверждения, как у нынешней кнопки.
- Код комнаты остаётся мелкой строкой: вход по коду живёт.
- У занятого места хозяин меняется местами только с собой; напарника каждый выбирает сам через «в напарники».
- Проверки разработчик держит во временной папке, `tests/` — у тестировщика.
