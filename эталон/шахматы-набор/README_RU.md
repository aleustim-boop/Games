# Шахматы — ассеты для Telegram Mini App

Готовый пакет собран по двум экранам: шахматный gameplay и структура lobby в стиле существующего приложения «Игры с друзьями».

## Что внутри

- `lobby/` — шахматная плитка, исходная hero-сцена и готовый широкий баннер без текста.
- `gameplay/` — рамка доски, текстуры светлой/тёмной клетки, пустая доска-превью, подсветки и 12 чистых фигур с прозрачным фоном.
- `shared/` — фоновая текстура и точные токены цвета/геометрии.
- `references/` — неизменённые исходники и контрольная сборка фигур.
- `ASSET_MANIFEST.csv` и `ASSET_TABLE_RU.md` — назначение, размеры и порядок слоёв каждого файла.
- `CLAUDE_CODE_INSTRUCTIONS_RU.md` — готовая инструкция для подключения в проект.
- `QA_REPORT_RU.md` — результат проверки архива.

## Важное о качестве

- Исходный игровой экран сохранён без изменений в размере **941×1672 px**.
- Два исходных шахматных изображения сохранены без изменений в размере **1536×1024 px**.
- Production-фигуры в `gameplay/pieces/` заново отрисованы по визуальному стилю макета на прозрачном фоне и сохранены как **384×384 px**. Это новые производные ассеты, а не апскейл маленьких фигур.
- Точные нативные вырезки фигур из исходного экрана сохранены отдельно в `references/native_piece_crops/` в размере **101–102×101 px**. Они не увеличивались.
- `chess_hero_banner_876x204.png` — честная обрезка и уменьшение исходника 1536×1024 для места баннера. Новых деталей в нём не создавалось.
- `board_empty_preview_875x875.png` — техническое превью: рамка взята из макета, а пустое поле собрано из двух реальных образцов деревянных клеток.

## Что брать для реализации

Для lobby используйте `lobby/chess_hero_banner_876x204.png`. Заголовки, рейтинг, режим игры, контроль времени, сложность бота, кнопки и нижнюю навигацию создавайте HTML/CSS/React-кодом.

Для gameplay собирайте доску слоями:

1. HTML-контейнер доски.
2. 64 клетки из `square_light_101x101.png` и `square_dark_101x101.png`.
3. Подсветка последнего хода или выбранной клетки.
4. PNG-фигуры из `gameplay/pieces/`.
5. Возможные ходы — CSS-круг или `move_dot_101x101.png`.
6. `board_frame_overlay_875x875.png` поверх сетки, если нужны точные деревянная рамка и координаты из макета.

Не используйте `board_reference_with_position_875x875.png` как интерактивную доску: фигуры и подсветки в нём уже запечены. Это только визуальный эталон.

## Масштабирование

Базовый холст макета — 941×1672. Масштабируйте интерфейс пропорционально ширине Telegram WebView. Доску держите квадратной через `aspect-ratio: 1 / 1`; фигура занимает одну клетку и рендерится через `object-fit: contain`.

```css
.chess-board { position: relative; width: 100%; aspect-ratio: 1; }
.chess-grid { position: absolute; inset: 3.31% 3.66% 4.34% 3.66%; display: grid; grid-template-columns: repeat(8, 1fr); }
.chess-piece { width: 100%; height: 100%; object-fit: contain; pointer-events: none; }
.board-frame { position: absolute; inset: 0; width: 100%; height: 100%; pointer-events: none; z-index: 40; }
```

Точные имена и слои находятся в `ASSET_TABLE_RU.md`. Финальная спецификация генеративного атласа фигур сохранена в `IMAGEGEN_PROMPT_RU.md`.
