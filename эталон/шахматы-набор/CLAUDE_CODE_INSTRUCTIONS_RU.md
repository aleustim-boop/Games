# Инструкция для Claude Code

## Цель

Подключить шахматы в существующий Telegram Mini App «Игры с друзьями», сохранив тёмную тему, лаймовый акцент и визуальный язык текущих экранов.

## Жёсткие правила

1. Не вставлять lobby или gameplay одним скриншотом.
2. Не запекать в изображения тексты, рейтинг, таймеры, имена игроков, историю ходов и кнопки.
3. Не увеличивать растровые фигуры заранее. Масштабировать их только браузером до размера клетки.
4. Не изменять шахматную позицию через Photoshop: состояние доски должно приходить из игрового движка.
5. `references/` не импортировать в production bundle.
6. В названиях компонентов и путях использовать латиницу; готовые ассеты уже названы латиницей.

## Экран lobby

Собрать кодом:

- верхнюю панель: назад, «Игры с друзьями», меню;
- заголовок «Шахматы» и подзаголовок «Выберите игру и соперника»;
- кнопку «Правила»;
- рейтинг игрока;
- переключатель «С ботом / Онлайн»;
- контроль времени: «Блиц 5+3», «Рапид 10+0», «Классика 30+0»;
- сложность бота: «Лёгкая / Средняя / Сложная»;
- главную кнопку: «Играть с ботом» или «Найти соперника»;
- таблицу рейтинга и нижнюю навигацию.

Изображение `lobby/chess_hero_banner_876x204.png` разместить внутри hero-карточки как `background-image`. Левая часть намеренно затемнена под рейтинг/подпись, но весь текст должен быть DOM-элементами.

## Экран gameplay

Состояние позиции хранить отдельно, например в FEN. В эталонном скриншоте показана позиция после `1. e4 e5 2. Кf3`; это только визуальная проверка, а не стартовое состояние.

Рекомендуемая DOM-структура:

```text
game-screen
├── app-header
├── game-title
├── opponent-panel + timer
├── chess-board
│   ├── chess-grid (64 cells)
│   ├── last-move overlays
│   ├── legal-move overlays
│   ├── pieces
│   └── board-frame overlay
├── player-panel + timer
├── turn-status
├── move-history
└── actions: draw / resign / chat
```

## Координаты и ориентация

- Белые находятся снизу.
- `a1` — тёмная клетка.
- При игре чёрными поворачивать и сетку, и подписи координат.
- Не менять DOM-порядок истории ходов при визуальном повороте доски.

## Слои доски

| z-index | Слой | Реализация |
|---:|---|---|
| 0 | клетки | 64 DOM-элемента с двумя текстурами |
| 10 | последний ход | CSS или `highlight_last_move_101x101.png` |
| 20 | фигуры | PNG из `gameplay/pieces/` |
| 30 | выбранная клетка/доступные ходы | CSS или PNG overlays |
| 40 | рамка и координаты | `board_frame_overlay_875x875.png` |
| 50 | drag-preview | временная копия фигуры в портале |

## Интерактивность

- Клик по своей фигуре выбирает клетку и показывает допустимые ходы.
- Второй клик выполняет ход либо снимает выбор.
- Drag-and-drop поддержать дополнительно, но не делать единственным способом управления.
- Таймеры, очередь хода и история должны обновляться из состояния игры.
- Во время ожидания хода отключить выбор своих фигур и показать статус «Ход соперника».
- Для клавиатуры и screen reader каждой клетке дать `aria-label`, например `e4, белая пешка`.

## Какие элементы рисовать кодом

Все надписи, кнопки, контуры панелей, переключатели, таймеры, индикатор загрузки, аватары-заглушки, иконки назад/меню/часов/ничьей/флага/чата, рейтинг, координаты при динамическом повороте и история ходов. Для иконок используйте SVG-компоненты, не символы Unicode.
