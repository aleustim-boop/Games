# Дурак — набор изображений для экрана игры

Нарезка предоставленного макета 941×1672 px. В архиве 32 фрагмента PNG в исходном размере и версиях ×2, 11 SVG-иконок, исходный макет, карта файлов и JSON с координатами.

## Задание для Claude Code

Прочитай этот README, затем `ASSET-MAP.md` и `assets-manifest.json`. Открой `reference/full-layout.png`. Перенеси оформление в существующий экран игры «Дурак», сохраняя текущую игровую логику. Не заменяй работающий экран целым скриншотом и не используй нарисованное состояние партии как источник правил.

PNG — точные прямоугольные вырезки с исходным фоном. Они НЕ являются прозрачными спрайтами. Большинство файлов предназначено для сверки оформления: карты перекрываются, кнопки содержат готовые подписи, стол содержит карты. Машинное поле `usage` различает `reference` (образец), `crop` (отдельная видимая карта с фоном) и `texture` (образец материала). Даже `crop` требует учета фона и скруглений.

Для статичной демонстрации можно использовать составные фрагменты. Для работающей игры сверстай панели, стол и состояния кодом, подключи существующую полноценную колоду. Фотографии используй согласно ограничениям ниже. Не накладывай новый текст на фрагмент, в котором этот же текст уже присутствует.

При ширине 390 CSS px масштаб относительно макета около 0,414: основные поля около 13–14 px, стол около 383×258 px. Это ориентир для сравнения; не масштабируй весь интерфейс одной картинкой. Исходные надписи некоторых кнопок после такого уменьшения станут мелкими: живые подписи подгони под читаемость. Минимальная интерактивная область — 44×44 CSS px. Учитывай безопасные отступы Telegram и системные safe-area. В низком окне разреши прокрутку или адаптируй высоту стола; нижние кнопки не должны перекрывать руку.

## Игровой стол и карты

### Стол

`sections/native/table-with-cards.png` уже содержит колоду, подпись козыря и три карты на поле. Нельзя использовать его как фон под новые карты: старые останутся видимы.

Для интерактивного стола создай отдельный контейнер с темно-красным фоном, скругленной деревянной рамкой и внутренней тенью. `textures/native/red-felt.png` — чистое сукно без объектов, `wood-rail.png` — образец древесины. Они не подготовлены как бесшовные текстуры: повторение может давать швы; используй с осторожностью либо возьми цвета и характер материала для CSS. Восстановленного пустого стола в архиве нет.

### Колода и соперник

- Колода находится сверху слева на столе: `table/native/deck-with-trump.png`.
- Козырь на макете — черви, видна 8 червей. `cards/native/eight-hearts-partial.png` содержит только узкую видимую часть, не полную карту.
- Справа от колоды — надпись «Козырь», масть и «В колоде: 21». Эти значения выводить из игровой модели, не фиксировать строкой.
- `ui/native/opponent-hand.png` показывает 6 перекрывающихся рубашек. Для игры выводить нужное число карточек отдельно, не размножать картинку всего веера.
- `cards/native/back.png` — полностью видимая крайняя правая рубашка. Скругленные углы содержат фон панели; при использовании ограничь изображение скруглением, проверь края. Это не прозрачный вырезанный объект.

## Размеры и качество

PNG в `native/` сохраняют исходные пиксели. В `2x/` обе стороны увеличены в два раза методом Lanczos, без генеративной перерисовки. Новые настоящие детали не добавлены. Например, стол имеет 923×622 px в оригинальной нарезке и 1846×1244 px в версии ×2. Не выдавай увеличение за исходные фото высокого разрешения.

Нарезка не убирает запеченные надписи, тени и перекрытия. В архиве нет прозрачных растровых карт, пустого восстановленного стола или полного набора колоды. Все эти ограничения указаны также у конкретных файлов, чтобы Claude Code не принял образцы за полноценные спрайты.

## Машиночитаемое описание

В `assets-manifest.json` у каждого изображения есть `path`, `upscaledPath`, `sourceBox`, `description`, `usage`, `transparent`. `sourceBox` = `[x, y, width, height]`, начало координат — левый верхний угол исходника. Координаты описывают область вырезки, а не обязательную абсолютную верстку для всех телефонов.

## Проверка после подключения

- Все динамические подписи, счетчики, таймер и состояния приходят из игры.
- На столе нет запеченных карт под настоящими картами.
- Перекрытые фрагменты не используются как полные карты; значения карт верны.
- Кнопка «Бито» корректно блокируется и включается; «Взять» и «Чат» работают.
- Выбранная карта подсвечивается отдельным слоем и не теряет обработчик нажатия.
- Весь веер доступен на узком экране; нижние действия не перекрывают карты.
- Нет дублирования шапки Telegram, текста и иконок поверх их растровых копий.
