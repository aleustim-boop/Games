Подключи дизайн нард из папки backgammon-assets к текущему Telegram Mini App.
Сначала прочитай CLAUDE.md внутри этой папки, docs/IMPLEMENTATION.md, assets-manifest.json и integration/board-geometry.json. Посмотри references/lobby-original.png и references/gameplay-original.png.
Сохрани существующую архитектуру, правила игры, авторизацию и сетевой код. Реализуй оба экрана максимально близко к макетам, используя готовые ассеты из lobby, gameplay, shared. Не накладывай целый скриншот вместо интерфейса.
Весь текст, рейтинг, имена, время, кнопки, вкладки, состояния и таблицы сделай кодом. Игровое поле — gameplay/board-empty.png, фишки — отдельные PNG. Координаты пунктов и порядок слоёв возьми из документации. Кубики — общий SVG-набор 1–6. Файлы references и фотосрезы кубиков используй только для визуального сравнения.
Проверь адаптивность 360/390/430 CSS px, прозрачность ассетов, кликабельность и отсутствие двойных надписей. Сравни оба экрана с исходными макетами. Не меняй правила нард по картинке: изображённая расстановка не является спецификацией игры.
