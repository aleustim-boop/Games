# Проверка и ограничения

- 69 изображений в каталоге: 38 для интерфейса, 31 для сравнения; дополнительные обзорные изображения находятся в docs.
- PNG декодированы полностью; найденный повреждённый срез рейтинга пересоздан и проверен повторно.
- Размеры файлов сверены с manifest.
- Alpha-канал проверен у всех вырезанных элементов с маской.
- SVG проверены как XML; точки на кубиках заданы явно для всех шести значений.
- Локальные ссылки картинок в preview.html проверены.
- Визуально осмотрены нарезка и сборка пустой доски с 15 фишками каждого цвета.
- Пустая доска восстановлена с повторением чистых текстур исходника. Возможны различия древесного узора и небольшие переходы между полосами.
- Тонкие края растровых иконок сохраняют сглаживание от тёмного исходного фона. Они предназначены для тёмного интерфейса; для другого цвета фона лучше использовать alpha-маску.
- Фотосрезы кубиков имеют ручную маску и предназначены для сравнения стиля.
- Шрифты, CSS-цвета и SVG-формы приблизительно воссозданы по макету.
- Мобильное приложение, Telegram API, сеть, игровые правила и бизнес-логика в рамках подготовки ассетов не проверялись.
