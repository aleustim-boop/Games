# Нарды: готовые изображения для Claude Code

1. Распакуйте архив в папку проекта, например `design/backgammon-assets/`.
2. Передайте Claude Code текст из `PROMPT_FOR_CLAUDE.txt`.
3. Для просмотра всех элементов откройте `docs/preview.html` обычным браузером. Интернет не нужен.

Что внутри:

- `lobby/` — фото доски для баннера, кубки, медали.
- `gameplay/` — пустая доска, две фишки с прозрачностью, кольца выделения, фотосрезы двух кубиков.
- `shared/` — общие иконки, текстуры, полный набор SVG-кубиков 1–6.
- `references/` — исходные макеты и точные срезы панелей, кнопок, переключателей. Это образцы для вёрстки.
- `docs/` — визуальный каталог, подписанные схемы экранов, техническое описание и таблица всех 69 изображений.
- `integration/` — CSS-параметры и координаты всех 24 пунктов доски.
- `CLAUDE.md` — основная инструкция по применению.
- `assets-manifest.json`, `ASSETS.csv` — машиночитаемый и табличный каталоги.

Качество: оба исходника — 941 × 1672 пикселя. PNG сохранены в исходном масштабе без искусственного увеличения. Для экрана шириной 390 CSS-пикселей это примерно 2,4 пикселя исходника на один CSS-пиксель. SVG масштабируются без пикселизации, но являются воссозданными векторами, а не вырезанными фотографиями.

Пустая доска восстановлена из чистых участков исходного поля: сохранены оригинальная рамка и петли, повторяются текстуры пунктов. Это не скрытый слой исходника и не новая детализированная отрисовка.
