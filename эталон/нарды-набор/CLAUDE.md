# Инструкция по использованию ассетов нард

Эта инструкция относится к дизайну из этого пакета. Она не требует менять устройство существующего приложения или переписывать игровые правила.

## Сначала открыть

1. `references/lobby-original.png` — лобби. Источник: `12_02_26(2).png`.
2. `references/gameplay-original.png` — игра. Источник: `12_02_15(2).png`.
3. `docs/IMPLEMENTATION.md` — состав экранов, размеры, слои, состояния.
4. `docs/ASSET_MAP.md` — каждый файл и назначение.
5. `integration/board-geometry.json` — координаты фишек относительно пустой доски.

## Обязательные принципы

- Полноэкранные макеты и `references/crops/` — для сравнения, не готовая подложка интерфейса. Иначе останутся неизменяемые имена, часы, рейтинги и фишки.
- В игре фон доски только `gameplay/board-empty.png`. Она без фишек и кубиков.
- Чёрные и светлые фишки — экземпляры `checker-black.png` и `checker-ivory.png`, каждая отдельным элементом.
- Текст, кнопки, круглые подложки аватаров, рамки, разделители, таблицы, градиенты, таймеры — DOM/CSS или принятый в проекте UI-движок.
- Свечение выбора и допустимые пункты — отдельные слои. Не использовать срез выбранной фишки как обычную фишку.
- Для игровых значений кубиков использовать весь набор `shared/dice/die-1.svg` … `die-6.svg`. Фотосрезы 2 и 3 лежат только для сравнения стиля: смешивать их с векторами в игре не нужно.
- Фото баннера `lobby/hero-board-scene.png` имеет собственный тёмный фон, не прозрачный. Разместить справа внутри карточки с обрезкой overflow, слева затемнить CSS-градиентом под рейтингом.
- Все пути в manifest относительны корню пакета. При копировании в public/assets/backgammon сохранить структуру; URL будет `/assets/backgammon/...`.
- Ресурсы `usage: reference` не загружать в рабочем интерфейсе. Полные исходники большие, нужны лишь разработчику.
- Исходники 941 × 1672. Размеры PNG реальны. Нельзя обещать HD после интерполяции. SVG воссозданы вручную геометрически, а не извлечены из оригинала.
- Пустая доска собрана из чистых полос исходного изображения. Допустимо заметное повторение древесной текстуры. Сохранены 24 пункта и исходная деревянная рамка.
- Макет не задаёт правила: в нём видно только 10 чёрных фишек. Расстановку определяет игровой движок. Не копировать это количество в стартовую позицию.
- Название «Классические» воспроизвести в UI как в лобби; не приравнивать автоматически к конкретному набору правил без проверки текущего проекта.

## Проверка результата

Оба экрана должны работать на ширине 360, 390 и 430 CSS px без горизонтального скролла. Сравнить с макетами при одинаковой ширине. Убедиться, что фишки, кубики, таймеры и выбранные режимы меняются независимо от фоновой картинки. Не заменять действующий backend демонстрационными данными из макета.
