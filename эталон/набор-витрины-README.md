# Игры с друзьями — изображения для интерфейса

Набор нарезан из предоставленного макета `reference/full-layout.png` (941×1672 px). Это ресурсы экрана выбора игр, а не игровые доски, карты или фигуры для самого игрового процесса.

## Начать здесь — инструкция для Claude Code

1. Посмотри `reference/full-layout.png` и прочитай этот README.
2. Сохрани текущую логику приложения. Подключи картинки как локальные assets; не используй весь скриншот вместо интерфейса.
3. Для максимально точного визуального совпадения используй отдельные полные карточки из `cards/native/`. В них уже есть название, стрелка, затемнение и рамка. Не рисуй эти элементы второй раз! Сделай всю карточку настоящей кнопкой с доступным именем `aria-label`.
4. Если нужны живые подписи, локализация и гибкая верстка, используй `photos/native/`, а название, стрелку, рамку и затемнение реализуй кодом. Это более короткие кропы, а не восстановленные полноразмерные фоны. Такое решение будет немного отличаться по композиции от макета.
5. Не смешивай два режима внутри одной карточки. Не накладывай новые заголовки на `cards/`.
6. Кнопки категорий, заголовки и нижнюю навигацию сверстай кодом. Используй SVG из `icons/`; картинки `reference/ui/` нужны только как визуальные образцы.
7. Привяжи карточки к существующим экранам соответствующих игр. Если игра не реализована, показывай честное состояние «Скоро», не создавай фиктивный работающий маршрут.
8. Сверь результат на мобильных ширинах 360, 390 и 430 CSS px. Тексты должны читаться, интерактивные области — не меньше 44×44 CSS px. Учитывай безопасные отступы и существующую шапку Telegram, не дублируй системные элементы.

### Компоновка и поведение

- Экран темный, две колонки, последняя карточка занимает обе.
- В исходнике ширина контента около 873 px; поля слева и справа около 34 px; промежуток между колонками 17 px; между рядами около 15–16 px. Это координаты изображения, не CSS-пиксели телефона.
- Для ориентира на экране 390 CSS px: боковые поля примерно 14 px, промежутки 7 px, радиусы карточек около 12 px. Не растягивай макет до 941 CSS px на телефоне.
- Высоты рядов в макете различаются. Для точного совпадения сохрани пропорции каждой карточки из таблицы. Не принуждай все картинки к формату 3:2 и не растягивай их независимо по осям.
- Режим полных карточек: `<img>` с `width:100%; height:auto; display:block`. Изображения уже содержат скругления и узкую рамку; в углах остался исходный фон, прозрачности нет. Лучше использовать близкий темный фон страницы.
- Режим отдельных фото: для первых шести карточек сохраняй полную ширину фото и его пропорции; живой заголовок расположи в отдельной нижней темной зоне. Вариант с наложением заголовка тоже допустим, но закрывает часть предметов. Нельзя ожидать точного восстановления исходной композиции.
- Подписи первых шести игр — снизу слева, стрелка — снизу справа. «Морской бой» должен помещаться целиком; при необходимости слегка уменьши размер текста, не обрезай название.
- «Деберц»: заголовок слева, ниже «Карточная классика», фото карт справа, стрелка у правого края. `photos/native/deberts.png` — прямоугольный фрагмент правой части на зеленом фоне, не прозрачные карты. При живой верстке используй темно-зеленый фон баннера и мягкое затемнение на стыке. Для точного совпадения выбирай полную карточку `cards/native/deberts.png`.
- Верхний заголовок: «Во что сыграем?». Подзаголовок: «Собирай друзей. Играй в любимое.».
- Фильтры: «Все» (выбран), «Настольные», «Карточные». Активный — лаймовый с темным текстом, остальные — темные с серой обводкой.
- Нижние разделы: «Игры» (выбран), «Друзья», «Профиль». Нижнюю панель закрепи, зарезервируй под нее место в прокрутке, учитывай safe-area. Баннер «Деберц» не должен перекрываться навигацией.
- Шапку «Игры с друзьями», крестик и троеточие рисуй в контенте только если они не предоставляются самим контейнером Telegram.
- Цвета для старта, приблизительно по макету: фон `#101416`, основной текст `#F8F5EB`, вторичный `#858B94`, акцент `#D2F76B`, граница `#51575E`. Шрифт исходника неизвестен; используй системный sans-serif или имеющийся шрифт приложения с поддержкой кириллицы, сверяя ширину текста.

| `more.svg` | Дополнительное меню собственной шапки, если оно нужно; светлый цвет |

SVG — аккуратные векторные аналоги по мотивам исходника, не извлеченные оригинальные контуры. Используют `currentColor`: подключай inline или через SVG-компонент, чтобы цвет наследовался. У внешнего `<img src="...svg">` цвет от родителя не наследуется. Для декоративных иконок ставь `aria-hidden="true"`, имя действия задавай кнопке.

## Качество и ограничения

Исходник — единое растровое изображение 941×1672, не слоистый дизайн-файл. Поэтому настоящих отдельных фотографий в 4K здесь нет. `native` сохраняет доступные исходные пиксели; `2x` — качественная интерполяция Lanczos без генеративной перерисовки, без новых реальных деталей. Обычная карточка ×2 имеет ширину 856 px; баннер «Деберц» — 1746 px. Для мобильной карточки шириной около 175–200 CSS px исходные фрагменты уже подходят примерно для плотности 2×.

Текст, рамки и тени нельзя без изменений отделить от фотографии там, где они перекрывают предметы. Для `photos/` такие зоны обрезаны, а не дорисованы. У «Деберца» карты уже обрезаны нижней границей самого макета. Буквы, масти и значения на игральных картах сохранены как в исходнике — запрет интерфейсных надписей на них не распространяется. Возможные ошибки изображения досок или игровых значений тоже не исправлялись: эти фото декоративные, не игровые данные.

Для крупного десктопного показа с новой детализацией потребуются оригиналы фотографий либо отдельная генерация по референсу, которая уже не будет точной нарезкой. Не выдавай версии ×2 за фотографии с восстановленными деталями.

## Проверка после подключения

- Все 7 игр на правильных местах; у Деберца ширина в две колонки.
- Нет повторных подписей и стрелок поверх полных карточек.
- Сами кнопки, фильтры и вкладки интерактивны, не заменены скриншотами.
- Фотографии не растянуты; нижняя навигация ничего не перекрывает.
- В интерфейс не загружены одновременно native и 2x без необходимости.
- Декоративные фото не используются как спрайты для игрового процесса.

`assets-manifest.json`: `sourceBox` задан как `[x, y, width, height]` в пикселях исходника. `row` и `column` нумеруются с 1. Доступные пути относительны корню этого архива.
