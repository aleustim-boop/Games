# Промпты генерации

Режим: встроенная генерация изображений.

## Lobby

`ui-mockup`: полноэкранное мобильное лобби русских шашек в стиле существующего экрана «Игры с друзьями»: тёмный charcoal UI, тёплая деревянная доска, объёмные чёрные и светлые шашки, лаймовый акцент; режим бот/онлайн, русские/международные, сложность, рейтинг и CTA. Все русские надписи заданы дословно. Нативный рендер без апскейла.

## Чёрная шашка

`background-extraction`: одна изолированная объёмная чёрная шашка из полированного бакелита, ракурс как в gameplay, толстый профиль, фаски, концентрическое углубление, реальные блики; настоящий прозрачный фон, без доски, текста и короны. Нативный рендер, не увеличение скриншота.

## Светлая шашка

`background-extraction`: одна изолированная объёмная шашка тёплого цвета слоновой кости, тот же ракурс и форма, мягкие фаски и блики; настоящий прозрачный фон, без доски, текста и короны. Нативный рендер, не увеличение скриншота.

Полные англоязычные производственные формулировки использовались только для генератора. В README зафиксировано происхождение файлов и отсутствие искусственного повышения детализации.
