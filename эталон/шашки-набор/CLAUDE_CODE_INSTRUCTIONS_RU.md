# Инструкция для Claude Code

## Цель

Подключить русские шашки к существующему Telegram Mini App «Игры с друзьями», повторив два reference-экрана, но собрав интерфейс из кода и отдельных ассетов.

## Жёсткие правила

1. Не вставлять экран lobby или gameplay одним большим скриншотом.
2. Не запекать в PNG надписи, рейтинг, таймеры, имена, историю хода или кнопки.
3. `references/` не импортировать в production bundle.
4. Состояние доски должно приходить из игрового движка, а не из фонового изображения.
5. Сохранять ориентацию: `a1` — тёмная клетка, светлые снизу.
6. Все шашки могут стоять только на тёмных клетках.
7. Не увеличивать растровые исходники при сборке. Браузер масштабирует production-PNG до клетки.
8. Для дамки не масштабировать/дублировать PNG: добавить кодовый SVG-маркер короны поверх обычной шашки.

## Lobby: создать кодом

- верхнюю панель: назад, «Игры с друзьями», меню;
- заголовок «Шашки» и подзаголовок «Выберите игру и соперника»;
- кнопку «Правила» и модальное окно правил;
- рейтинг игрока `1 240`;
- режим `С ботом / Онлайн`;
- вариант `Русские / Международные`;
- сложность `Лёгкая / Средняя / Сложная`;
- CTA `Играть с ботом` или `Найти соперника`;
- подпись `Тренировка не влияет на рейтинг`;
- таблицу рейтинга;
- нижнюю навигацию `Игры / Друзья / Профиль`.

В `RatingHero` используйте `lobby/checkers_hero_banner_876x205.png` как фоновое изображение. Трофей, подпись и число рейтинга должны находиться поверх него в DOM.

Рекомендуемые состояния:

```ts
type GameMode = 'bot' | 'online';
type CheckersVariant = 'russian' | 'international';
type BotDifficulty = 'easy' | 'medium' | 'hard';
```

Пока нет отдельного поля 10×10, `international` должен быть disabled или помечен `Скоро`.

## Gameplay: состояние и правила

Минимальная модель клетки и фигуры:

```ts
type Side = 'black' | 'ivory';
type Square = { row: number; col: number };
type Piece = { id: string; side: Side; king: boolean; square: Square };
```

Для русских шашек реализовать:

- поле 8×8, по 12 шашек в стартовой позиции;
- простая шашка ходит по диагонали вперёд на одну клетку;
- взятие обязательно, простая шашка бьёт вперёд и назад;
- при серии взятий ход продолжается той же шашкой;
- дамка ходит по диагонали на любое число свободных клеток;
- превращение на последней горизонтали;
- окончание партии при отсутствии шашек или допустимых ходов;
- ничья и сдача обрабатываются игровым состоянием/сервером.

Проверяйте правила игровым движком; UI не должен самостоятельно разрешать нелегальные ходы.

## Координаты и начальная позиция

- `a1` находится слева снизу и является тёмной клеткой.
- Чёрные: `b8 d8 f8 h8`, `a7 c7 e7 g7`, `b6 d6 f6 h6`.
- Светлые: `a3 c3 e3 g3`, `b2 d2 f2 h2`, `a1 c1 e1 g1`.
- В reference gameplay показан последний ход `c3–d4`: `c3` пустая и обведена, светлая шашка стоит на `d4`.
- При игре чёрными визуально поворачивать клетки и координаты, но не менять внутреннюю систему координат движка.

## Слои доски

| z-index | Слой | Реализация |
|---:|---|---|
| 0 | клетки | 64 DOM-элемента с двумя деревянными текстурами |
| 10 | последний ход | CSS или `highlight_last_move_99x98.png` |
| 20 | шашки | два PNG из `gameplay/pieces/` |
| 25 | маркер дамки | SVG-корона внутри шашки |
| 30 | выбор/допустимый ход/взятие | CSS или PNG-оверлеи |
| 40 | рамка и координаты | CSS; optional `board_frame_overlay_874x853.png` |
| 50 | drag-preview | временная копия шашки в портале |

Рекомендуемый CSS-каркас:

```css
.checkers-board { position: relative; width: 100%; aspect-ratio: 1 / 1; }
.checkers-grid { position: absolute; inset: 4.8%; display: grid; grid-template: repeat(8, 1fr) / repeat(8, 1fr); }
.board-cell { position: relative; min-width: 0; min-height: 0; background-size: cover; }
.checker-piece { position: absolute; inset: 5%; width: 90%; height: 90%; object-fit: contain; pointer-events: none; }
.board-overlay { position: absolute; inset: 0; width: 100%; height: 100%; pointer-events: none; }
```

Reference-рамка слегка прямоугольная; для production предпочтителен квадратный CSS-контейнер с деревянной рамкой. Текстуры 99×98 использовать через `background-size: cover`.

## Интерактивность

- Тап по своей шашке выбирает её и показывает только легальные ходы.
- Если есть взятие, обычные ходы других шашек блокируются.
- Тап по подсвеченной клетке выполняет ход.
- Drag-and-drop можно добавить, но тап должен оставаться основным способом.
- Во время серии взятий не переключать игрока, пока серия не завершена.
- Во время чужого хода отключить ввод и показать `Ход соперника`.
- Таймеры синхронизировать с серверным временем, а не только с `setInterval` клиента.
- Каждой клетке дать `aria-label`, например `d4, светлая шашка`.
- Кнопки `Предложить ничью`, `Сдаться`, `Чат` должны иметь подтверждение там, где действие необратимо.

## Какие изображения использовать

- Lobby hero: `lobby/checkers_hero_banner_876x205.png`.
- Фон: `shared/dark_background_tile_256x256.png` или CSS-градиент из tokens.
- Клетки: `gameplay/square_light_99x98.png`, `gameplay/square_dark_99x98.png`.
- Шашки: `gameplay/pieces/checker_black_384x384.png`, `checker_ivory_384x384.png`.
- Оверлеи можно заменить CSS, если совпадает визуально.

## Какие элементы создавать кодом

Все надписи; верхняя и нижняя навигация; кнопки и их hit-area; контуры карточек; переключатели; таймеры; аватары; online-индикатор; таблица рейтинга; трофей и служебные иконки как SVG; клетки и координаты; маркер дамки; состояния hover/pressed/disabled/loading; модальные окна; чат; поиск соперника; логика партии и анимации ходов.

## Telegram Mini App

- Учесть `safe-area-inset-top` и `safe-area-inset-bottom`.
- Поддержать ширины 320, 375, 390 и 430 CSS px.
- Не привязывать интерактивные зоны к пиксельным координатам reference-скрина.
- Для тактильной обратной связи использовать Telegram WebApp HapticFeedback, если API доступно.
