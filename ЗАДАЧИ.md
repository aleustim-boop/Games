Сюда штаб записывает **всё, что просит владелец** — сразу, как только просьба
прозвучала, ещё до того, как задача роздана исполнителям. Чтобы ничего не терялось
между разговорами.

Правила ведения (они же записаны в `CLAUDE.md`):

- **новая просьба записывается сразу**, словами владельца, ещё до раздачи исполнителям;
- **сдали или опубликовали — тоже сразу**, в тот же час;
- ничего не удаляем, даже отменённое: помечаем «отменено» и почему;
- время и числа берём из настоящих записей, а не по памяти.

**Важность — четыре уровня.** «Горит» — игрок видит поломку, берём немедленно.
«Скоро» — владелец ждёт, спросит на днях. «Потом» — нужное, но никто не ждёт.
«Задел» — пригодится, когда вырастем. Уровень ставит штаб, владелец меняет одним словом.

## Решения, принятые штабом без владельца

Чтобы не тормозить работу. Любое можно переиграть — скажите.

| Решение | Почему так |
|---|---|
| Шашки — отдельная страница; сперва только против бота | две игры на одной странице ломают друг друга; общий сервер не открывается |
| Рекорд в шашках — серия побед подряд по уровням; смена уровня серию не рвёт | правило общего хранилища, одно на обе игры |
| Рейтинг сперва личный; экран назван «Как я играю», а не «Рейтинг» | рейтинг — сравнение с другими, которого пока нет |
| Список знакомых — только те, с кем правда играл, взаимно; 60 дней, не больше 50 | Telegram не даёт контактов, и правильно делает |
| Токен бота доверен серверу комнат | та же машина; наружу не выходит, зовёт два метода |
| «Ну ты даёшь» в чат не попала | после чужой ошибки читается как насмешка |
| Витрина не пропускается по памяти; незаконченная партия — пометка, не автопереход | витрина, которая сама уводит, — не страница выбора |
| Статистика сервера отдаётся всем, кто спросит | одни счётчики, ни имён, ни номеров |
| Один тап «позвать» не делаем | сперва владелец посмотрит на список живьём |
