# Задачи и правки от владельца

Сюда штаб записывает **всё, что просит владелец** — сразу, как только просьба
прозвучала, ещё до того, как задача роздана исполнителям. Чтобы ничего не терялось
между разговорами.

**Живой дашборд (обновляется сам каждые 15 секунд):**
https://anniversary-kansas-fill-democrats.trycloudflare.com

пока включён компьютер (порт 8791, `node штаб/дашборд.js`, туннель `cloudflared`).
Адрес туннеля меняется при каждом его перезапуске — штаб обновляет эту строку.

Старая страница-снимок (обновлялась рукой, отставала):
https://claude.ai/code/artifact/73358d2f-387a-40f8-9be2-3ad78f79f9eb

Правила ведения (они же записаны в `CLAUDE.md`):

- **новая просьба записывается сразу**, словами владельца, ещё до раздачи исполнителям;
- **сдали или опубликовали — тоже сразу**, в тот же час;
- ничего не удаляем, даже отменённое: помечаем «отменено» и почему;
- время и числа берём из настоящих записей, а не по памяти.

**Важность — четыре уровня.** «Горит» — игрок видит поломку, берём немедленно.
«Скоро» — владелец ждёт, спросит на днях. «Потом» — нужное, но никто не ждёт.
«Задел» — пригодится, когда вырастем. Уровень ставит штаб, владелец меняет одним словом.

## ЧИТАТЬ ПЕРВЫМ ДЕЛОМ ПОСЛЕ ПЕРЕЗАПУСКА

**1. Поднять службы** — каждую отдельной короткой командой, в фоне:

- сервер комнат: `node server/сервер.js 8790` (порт 8765 занят чужой программой);
- страница игры: `node tests/локальный-сервер.js 8080`;
- бот: `node bot/бот.js`;
- живой дашборд: `node штаб/дашборд.js` (порт 8791) и туннель к нему
  `cloudflared tunnel --url http://127.0.0.1:8791` — новый адрес вписать в шапку;
- туннель игры — `cloudflared`, проверить `tasklist`.

Проверка: `curl -s http://127.0.0.1:8790/` → `{"живой":true,...}`.

**2. Списки ведут программы, а не память штаба.** Расписаний больше нет — они
будили сессию 36 раз в час и жгли лимит владельца впустую. Вместо них две
короткие команды, и звать их надо при каждой постановке и при каждой сдаче:

- `node штаб/в-работе.js` — раздел «В работе», по файлу `штаб/в-работе.json`.
  Время начала программа ставит сама из часов машины;
- `node штаб/списки.js` — очередь, вопросы к владельцу и «Готово», по файлу
  `штаб/списки.json`. Сделанное вычёркивает сама — по следу в коде (появился
  файл, есть строка), а время берёт из записей git.

**Ставя новую задачу в очередь, пиши примету «сделано»** — по какому следу в
коде будет видно, что дело готово. Без неё пункт придётся вычёркивать руками,
и мы вернёмся к тому, с чего начали: очередь висела девятью задачами, пять из
которых давно были у игроков. Формат — в шапке `штаб/сделано.js`.

Отдельно: искать сделанное по словам из заголовков коммитов **не годится** —
проверено на настоящих записях, четыре из пяти находит, а на пятом даёт ложное
срабатывание. Поэтому такой способ только подсказывает «проверьте», но права
вычёркивать не имеет.

**3. Раздать работу заново** по таблице «В работе» ниже: контекст исполнителей
теряется, сделанное остаётся в файлах — каждому сказать «посмотри, что уже лежит
в твоём файле, и продолжи».

**4. Номера версий** в `index.html` сейчас: `game.js?v=54`, `style.css?v=28`,
`telegram.js?v=12`, `сеть.js?v=28`. Правишь файл — поднимай номер.

**5. Что осталось непроверенным живьём** (нужен глаз человека, не робота):
переезд рекордов между двумя устройствами; шашки в настоящем Telegram (разворот,
стрелка «Назад», серия, звук); бросок заходной по сети между двумя живыми людьми.

## Ждём слова владельца

Это не долг команды и не очередь: тут работы на несколько строк, но решать
должен владелец — это его игра. Пока ответа нет, пункты стоят, и стоят они
не по нашей лени. Раздел ведёт `node штаб/списки.js`.

| О чём | Вопрос владельцу | Почему спрашиваем |
|---|---|---|
| Серия побед в счёте | **Рвать ли серию побед на сложном уровне, если проиграл на лёгком?** | работы тут на одну строку. Но это правило игры, а правила ваши: сейчас поражение на лёгком гасит все серии сразу |
| Прямой вход «Дурак с ботом» на витрине | **Сделать ли кнопку, которая сразу начинает партию с ботом?** | сейчас до партии четыре касания. Дорого это или нет — видно только вам, вы играете |
| Звук отказа в шашках | **Нужен ли короткий звук, когда ход запрещён?** | одна строка работы. Кому-то такой звук помогает, кого-то раздражает — решаете вы |

## Долги команды

**Честно: это не очередь, а список долгов, и он почти не движется.** Каждый
раз, когда владелец просит новое, его просьба справедливо обгоняет уборку —
и правильно. Держим список, чтобы долги не забылись, но не делаем вид, что
они «в очереди на завтра». Берём их, когда нет ни одного «горит» и «скоро».

| Что | Заметка |
|---|---|
| Стенды по шашкам и девять проверок серверщика перенести в `tests/` | ловцы ошибок исчезнут с концом сессии |
| Сервер: три копии «хранилища на диске» свести в одну; словари слов брать из правил | девять замечаний серверщика по уборке |
| Правила: пять склонений в одно, шесть «есть ли дверь» в одно | файл дорос до восьми тысяч строк |
| Вынести правила дурака из `js/game.js` в свой файл | путь у сервера и тестов, порядок подключения у страницы |
| Сверять зерно раздачи дня на сервере | пока результату верим на слово: это счёт, не право |
| Шашки: «спрятать плашку итога» в двух копиях, три копии обёртки настроек | резать, когда появится третий экран или четвёртая копия |
| Шашки берут шесть id у дурака ради его стилей | скрытая связь: переименует оформитель дурака — у шашек слетит вид |

## Решения, принятые штабом без владельца

Чтобы не тормозить работу. Любое можно переиграть — скажите.

| Решение | Почему так |
|---|---|
| Шашки — отдельная страница; сперва только против бота | две игры на одной странице ломают друг друга; общий сервер не открывается |
| Рекорд в шашках — серия побед подряд по уровням; смена уровня серию не рвёт | правило общего хранилища, одно на обе игры |
| Рейтинг сперва личный; экран назван «Как я играю», а не «Рейтинг» | рейтинг — сравнение с другими, которого пока нет |
| Список знакомых — только те, с кем правда играл, взаимно; 60 дней, не больше 50 | Telegram не даёт контактов, и правильно делает |
| Токен бота доверен серверу комнат | та же машина; наружу не выходит, зовёт два метода |
| «Ну ты даёшь» в чат не попала | после чужой ошибки читается как насмешка |
| Витрина не пропускается по памяти; незаконченная партия — пометка, не автопереход | витрина, которая сама уводит, — не страница выбора |
| Статистика сервера отдаётся всем, кто спросит | одни счётчики, ни имён, ни номеров |
| Один тап «позвать» не делаем | сперва владелец посмотрит на список живьём |
