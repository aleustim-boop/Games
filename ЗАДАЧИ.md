# Задачи и правки от владельца

Сюда штаб записывает **всё, что просит владелец** — сразу, как только просьба
прозвучала, ещё до того, как задача роздана исполнителям. Чтобы ничего не терялось
между разговорами.

**Дашборд для телефона:** https://claude.ai/code/artifact/73358d2f-387a-40f8-9be2-3ad78f79f9eb
— то же самое, но коротко и с оценкой времени. Обновляется вместе с этим файлом.

Правила ведения (они же записаны в `CLAUDE.md`):

- **новая просьба записывается сразу**, словами владельца, ещё до раздачи исполнителям;
- **сдали или опубликовали — тоже сразу**, в тот же час;
- ничего не удаляем, даже отменённое: помечаем «отменено» и почему;
- время и числа берём из настоящих записей, а не по памяти.

**Важность — четыре уровня.** «Горит» — игрок видит поломку, берём немедленно.
«Скоро» — владелец ждёт, спросит на днях. «Потом» — нужное, но никто не ждёт.
«Задел» — пригодится, когда вырастем. Уровень ставит штаб, владелец меняет одним словом.

**Последний раз правился: 7 сентября 2026, 17:35.**

## Решения, принятые штабом без владельца

Чтобы не тормозить работу. Любое можно переиграть — скажите.

| Решение | Почему так |
|---|---|
| Шашки — отдельная страница, а не внутри игры в дурака | две игры на одной странице ломают друг друга загадочным образом |
| Шашки сперва только против бота, игра вдвоём — потом | так общий сервер вообще не открывается и дурак не рискует |
| Рекорд в шашках — серия побед подряд по уровням | понятно новичку и красиво растёт |
| Рейтинг сперва личный, общий — когда будет постоянный сервер | личный работает всегда, даже когда компьютер выключен |
| Список знакомых — только те, с кем правда играл, и только взаимно | Telegram не даёт список контактов, и правильно делает |
| Знакомые забываются через 60 дней, не больше 50 человек | два месяца — срок, за который «мы играли» ещё правда |
| Фраза «Ну ты даёшь» в чат не попала | после чужой ошибки читается как насмешка. «Ходи уже» заменено на «Жду ваш ход» |
| Бить максимум в шашках не обязательно | это русские шашки, а не международные |
| Токен бота доверен серверу комнат | он на той же машине; читается из `bot/.env`, наружу не выходит, зовёт два метода |
