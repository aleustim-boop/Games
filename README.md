# Подкидной дурак — игра для Telegram

Карточная игра «Подкидной дурак» против бота. Открывается прямо внутри Telegram
по кнопке «Играть» — ничего скачивать и устанавливать не нужно. Играть можно и просто
в браузере на компьютере.

Рекорды (самая длинная серия побед подряд) сохраняются сами: внутри Telegram —
в вашем личном облаке Telegram, поэтому они видны и на телефоне, и на планшете;
в обычном браузере — в памяти самого браузера.

Никаких платных сервисов и своей базы данных проекту не нужно.

---

## 1. Как получить файлы игры и открыть её у себя на компьютере

### Сначала скачайте файлы

Если папки с игрой у вас на компьютере ещё нет, возьмите её с GitHub — это бесплатное
хранилище, где лежит проект:

1. Откройте страницу проекта на <https://github.com>.
2. Нажмите зелёную кнопку **Code** (в правой части, над списком файлов).
3. В выпавшем окошке выберите **Download ZIP** — начнётся скачивание архива.
4. Найдите скачанный файл (обычно папка «Загрузки»), щёлкните по нему правой кнопкой
   и выберите «Извлечь всё» («Распаковать»). Появится обычная папка с файлами.

Внутри должны быть `index.html`, `style.css` и папки `js`, `bot`, `tests`.
Это и есть «папка проекта», о которой говорится дальше.

### Теперь откройте игру

Самый простой способ: найдите в папке проекта файл `index.html` и откройте его
двойным щелчком. Игра запустится в браузере.

Если хочется «как в интернете» (некоторые браузеры строже относятся к файлам с диска),
запустите маленький встроенный сервер. Для этого нужен Node.js — бесплатная программа
для запуска таких скриптов, скачивается на <https://nodejs.org> (берите версию LTS).

Откройте командную строку в папке проекта и наберите:

```
node tests/локальный-сервер.js 8123
```

Затем откройте в браузере адрес <http://127.0.0.1:8123/index.html>.
Чтобы остановить сервер, нажмите в командной строке Ctrl+C.

## 2. Как создать своего бота в Telegram

Бот — это «дверь» в игру: он показывает кнопку «Играть».

1. Откройте Telegram и найдите бота **@BotFather** (это официальный бот Telegram
   для создания других ботов).
2. Напишите ему команду `/newbot`.
3. Он спросит название бота (любое, например «Подкидной дурак») и имя-адрес,
   которое должно заканчиваться на `bot` — например `moy_durak_bot`.
4. В ответ BotFather пришлёт **токен** — длинную строку из двух частей через двоеточие,
   вроде `1234567890:AA...`. Это пароль от вашего бота.

**Токен никому не показывайте и никуда, кроме файла настроек, не вставляйте.**
Если случайно показали — напишите BotFather команду `/revoke`, и он выдаст новый.

---

## 3. Куда положить токен

Токен лежит в одном-единственном файле: `bot/.env`. Этот файл не попадает
в репозиторий (в общее хранилище кода) — так и задумано.

1. Зайдите в папку `bot`.
2. Скопируйте файл `.env.example` и назовите копию просто `.env` (без «.example»).
3. Откройте `.env` любым текстовым редактором (подойдёт «Блокнот») и заполните две строки:

```
BOT_TOKEN=сюда вставьте свой токен от BotFather
GAME_URL=https://ваш-логин.github.io/Games/
```

`GAME_URL` — это адрес, по которому игра опубликована в интернете (как его получить,
написано в разделе 5). Он обязательно должен начинаться с `https://`:
Telegram открывает игру только по защищённому адресу.

Кавычки, пробелы вокруг знака «равно» и лишние переносы строк не нужны.

## 4. Как запустить бот-лаунчер

Нужен Node.js (см. раздел 1). Откройте командную строку в папке проекта и наберите:

```
node bot/бот.js
```

Если всё заполнено правильно, вы увидите примерно такое:

```
Бот запущен: @moy_durak_bot
Адрес игры:  https://ваш-логин.github.io/Games/
Напишите боту /start в Telegram. Остановить бота — Ctrl+C.
```

Теперь найдите своего бота в Telegram, напишите ему `/start` — придёт приветствие
с двумя кнопками:

- **Играть** — открывает игру прямо внутри Telegram;
- **Позвать друга** — Telegram покажет список ваших чатов; выберите человека,
  и ему уйдёт приглашение попробовать игру. Игры вдвоём по сети пока нет,
  это именно приглашение.

Пока команда `node bot/бот.js` работает в окне командной строки — бот отвечает.
Закрыли окно или нажали Ctrl+C — бот замолчал. Игра при этом продолжает быть
доступной по своему адресу.

Если что-то заполнено не так, программа не «упадёт» с непонятной ошибкой,
а прямо напишет по-русски, чего ей не хватает.

### Чтобы заработала кнопка «Позвать друга»

Один раз разрешите боту работать в режиме подсказок:

1. Напишите @BotFather команду `/setinline`.
2. Выберите своего бота.
3. На вопрос о подсказке ответьте любым текстом, например: `позвать друга`.

Без этого шага Telegram при выборе чата напишет «ничего не найдено».

## 5. Как опубликовать игру бесплатно (GitHub Pages)

GitHub Pages — бесплатная площадка, которая раздаёт обычные страницы по адресу
с `https`. Именно такой адрес и нужен Telegram.

1. Заведите бесплатную учётную запись на <https://github.com>.

2. Создайте репозиторий (папку-хранилище): кнопка **New** на главной странице
   или знак **+** в правом верхнем углу → **New repository**. Имя можно любое,
   например `Games`.

   **Обязательно выберите тип «Public» (открытый).** Это самое важное место:
   на бесплатном тарифе GitHub Pages раздаёт страницы только из открытых
   репозиториев. Если выбрать «Private» (закрытый), нужного пункта в настройках
   просто не окажется, и будет непонятно, почему ничего не работает.
   Открытый репозиторий не опасен: токен бота лежит в файле `bot/.env`,
   а он в репозиторий не попадает.

3. Загрузите файлы игры в репозиторий:

   - на странице репозитория нажмите **Add file** → **Upload files**;
   - откройте на компьютере папку с игрой, выделите всё её содержимое
     (`index.html`, `style.css`, папки `js`, `bot`, `tests`, файл `README.md`)
     и перетащите мышью в окно браузера, в поле с надписью
     «Drag files here to add them to your repository»;
   - дождитесь, пока все файлы появятся списком (папки загружаются целиком);
   - прокрутите страницу вниз и нажмите зелёную кнопку **Commit changes**
     («сохранить изменения»).

   Перетаскивать нужно **содержимое** папки, а не саму папку целиком: иначе
   `index.html` окажется на уровень глубже и адрес игры будет другим.

4. В репозитории откройте **Settings** (Настройки) → в левом меню **Pages**.
   Если пункта «Pages» нет — репозиторий закрытый (Private). Вернитесь в Settings,
   пролистайте в самый низ, найдите «Change repository visibility»
   и сделайте его открытым (Public).
5. В разделе «Build and deployment» → «Source» выберите **Deploy from a branch**,
   ветку **main** и папку **/ (root)**. Нажмите **Save**.
6. Подождите одну-две минуты и обновите страницу. Наверху появится адрес вида:

```
https://ваш-логин.github.io/Games/
```

7. Откройте этот адрес в браузере — должна открыться игра.
8. Впишите этот адрес в файл `bot/.env` в строку `GAME_URL=` и перезапустите бота.

Важно: файл `bot/.env` с токеном на GitHub не загружается — он специально исключён.
Проверьте, что в списке файлов на GitHub его действительно нет.

### Как потом обновлять игру: правило про номер версии

Это правило легко пропустить, а без него игроки неделями видят старую игру.

Браузеры (а Telegram — особенно упорно) запоминают файлы игры и потом берут их
из своей запоминалки, не спрашивая сервер заново. Чтобы этого не случилось,
в файле `index.html` к именам файлов приписан номер версии:

```html
<link rel="stylesheet" href="style.css?v=ЧИСЛО">
<script src="js/telegram.js?v=ЧИСЛО"></script>
<script src="js/game.js?v=ЧИСЛО"></script>
```

Вместо слова `ЧИСЛО` в настоящем `index.html` стоят цифры, и у каждого файла своя.
**Какие именно там числа сейчас — неважно, и приводить их к одинаковым не нужно.**
Ничего не исправляйте по этому примеру: он показывает только, как строка устроена.

**Правило одно: изменили `style.css`, `js/game.js` или `js/telegram.js` — увеличьте
на единицу то число, которое стоит у этого файла сейчас.** Стояло 5 — поставьте 6.
Делать это нужно в `index.html` до загрузки на GitHub, и только у того файла,
который вы правили. Уменьшать числа нельзя: для браузера это выглядит как
возврат к старой версии, и игроки снова увидят старую игру.

Проверить просто: откройте опубликованный адрес, и правка должна быть видна сразу,
без очистки истории браузера. Если правки не видно — почти всегда забыт номер версии.
Приписывать `?v=` к адресу самой игры бесполезно: номер должен стоять именно
в этих строках внутри `index.html`.

## 6. Как сделать кнопку «Играть» постоянной (по желанию)

Чтобы кнопка была всегда внизу чата с ботом, а не только в приветствии:

1. Напишите @BotFather команду `/setmenubutton`.
2. Выберите своего бота.
3. Отправьте адрес игры (тот же, что в `GAME_URL`).
4. Напишите название кнопки, например: `Играть`.

## 7. Что где лежит

```
Games/
├── index.html      главная страница игры — её и открывают
├── style.css       внешний вид
├── js/
│   ├── game.js     правила игры и соперник-бот
│   └── telegram.js связь с Telegram и хранение рекордов
├── bot/
│   ├── бот.js      бот-лаунчер: кнопка «Играть» и приглашение другу
│   ├── .env        ваши токен и адрес игры (не попадает в репозиторий)
│   └── .env.example образец этого файла с пояснениями
├── tests/          проверки игры
└── README.md       эта инструкция
```

## 8. Если что-то не работает

**«Не нашёл файл с настройками бота»** — вы ещё не сделали копию `.env.example`
под именем `.env`. Вернитесь к разделу 3.

**«Telegram не признал токен»** — токен скопирован не целиком или устарел.
Напишите @BotFather `/mybots`, выберите бота и возьмите токен заново.

**«Адрес игры должен начинаться с https://»** — Telegram не умеет открывать игру
с вашего компьютера (`http://localhost`). Сначала опубликуйте игру (раздел 5).

**«Похоже, этот же бот уже где-то запущен»** — вы запустили бота дважды.
Закройте лишнее окно командной строки: Telegram отдаёт сообщения только одной копии.

**Кнопка «Играть» есть, но игра не открывается** — проверьте, что адрес из `GAME_URL`
открывается в обычном браузере и начинается с `https://`.

**Кнопка «Позвать друга» пишет «ничего не найдено»** — не включён режим подсказок,
см. конец раздела 4.

**Поправили файл и загрузили на GitHub, а в игре всё по-старому** — забыт номер
версии. Поднимите `?v=` у изменённого файла в `index.html` (см. конец раздела 5).

**В настройках репозитория нет пункта «Pages»** — репозиторий закрытый.
На бесплатном тарифе Pages работает только из открытого (Public), см. раздел 5.

**Рекорды пропали** — если вы играли в обычном браузере и почистили его историю,
рекорды из памяти браузера удаляются вместе с ней. Внутри Telegram рекорды хранятся
в вашем облаке Telegram и так не теряются.
