# Правила для внешнего вида

- **Все игры выглядят одинаково** — это правило владельца. Ширина колонки, поля по краям, набор и порядок кнопок листа «⋯» («В меню · Как играть · Звук · Вибрация · Оформление · Рекорды»), нижняя полоса «Лобби · Рейтинг · Профиль» — одни на весь сборник и живут в общем `style.css`. Своё у игры только то, чего у других не бывает (доска, фигуры).
- **Образец — наборы владельца в `эталон/`**: страница тёмная, акцент один — салатовый; дерево, сукно, кость — с текстурой, фаской и тенью, плоская заливка запрещена.
- Новое общее правило добавляется **в общий файл**, не в файл игры; вид никогда не задаётся из JavaScript (кроме поведения вроде «эта часть прокручивается»).
- Изменил общий css — подними `?v=` у **всех** страниц, которые его просят, одним коммитом.
- «Как играть» доступна ДО партии; проверять на ширине 390 и 320.
- Экран нового вида не сдаётся без снимка: оформитель прикладывает путь к снимку, штаб смотрит глазами.
