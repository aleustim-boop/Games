# Правила для работы с сервером комнат

- **Клиенту не верим.** Всё, что уходит игроку, собирается вручную поле за полем в `видДляИгрока` (server/партия-по-сети.js). Новое поле ответа — только там; рука соперника, колода, отбой наружу выходят только числами.
- **Правила игр не раздваиваются.** Сервер require'ит те же файлы правил js/*, что и браузер. Правишь правила — правишь сразу обе стороны; после правки прогоняй самопроверку правил.
- **Боевой сервер на 8790 не перезапускать.** Комнаты живут в памяти: перезапуск закрывает все идущие партии. Перезапуск делает только штаб (`node штаб/перезапуск-сервера.js`), посмотрев `/` — сколько комнат живо. Проверочные копии — на других портах с `--без-памяти`, гасить по номеру процесса.
- Сервер стартует с require('../js/game.js') из рабочей папки — незагружающийся js кладёт сервер при следующем перезапуске: `node -e "require(...)"` из папки server/ до сдачи.
- Тексты отказов сервера — словами, понятными игроку; они показываются на экране как есть.
