# Правила для проверок

- **Сперва скрипт, браузер по остатку.** Всё, что можно проверить в node (правила прогоном, экранный код в песочнице vm с поддельным DOM/Telegram), проверяется скриптом одним запуском. Браузер — только живой взгляд и палец.
- **Каждая проверка обязана уметь краснеть**: ломающий запуск (флаг `--сломать` или подмена) портит проверяемое и требует провала. Не покраснела — чини проверку, а не верь зелёному.
- **Проверка читает устройство из того же файла, что и рисует его** — никаких вторых копий чисел и селекторов внутри проверки.
- Итог печатать строкой `Итого проверок: N, провалов: M`, при провале — выход с кодом 1.
- Пути — от папки проекта (`path.join(__dirname, '..')`), не из временных папок.
- Копии серверов — на свободных портах (не 8790!), поднимать самим и гасить по номеру процесса. Проверка, говорящая с чужой копией на порту, — ложь: сначала убедись, чья копия отвечает.
- Браузерные проверяющие работают по одному; второй браузер параллельно не открывать.
- Снимки — в снимки/ или tests/снимки/ с понятными именами; в корень проекта не класть.
- `\b` в regex не знает кириллицы — не использовать для кириллических имён.
