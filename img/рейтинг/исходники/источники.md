# Значки Катана и Монополии

Созданы встроенным ImageGen 25.09.2026 для замены буквенных заглушек в профиле и выборе игры рейтинга. Оригиналы с прозрачностью: `катан.png`, `монополия.png`. Рабочие PNG в родительском каталоге — 48×48 и 96×96 (@2x), уменьшены через Chromium Canvas с сохранением альфа-канала.

- Катан: объёмное красное деревянное поселение и золотая пшеница на зелёном гексе, тёплый студийный свет, без текста и рамки.
- Монополия: золотой металлический цилиндр, зелёный деревянный домик, две монеты, тот же свет и объём, без текста и рамки.

# Значки пяти одиночных игр (2048, судоку, блоки, три в ряд, змейка)

Созданы 29.09.2026 разработчиком — профиль и экран рейтинга просили эти файлы и получали 404, снаружи оставался запасной кружок с буквой. Ключи взяты из `js/игры-реестр.js` (совпали буква в букву с ожидаемыми: «2048», «судоку», «блоки», «три-в-ряд», «змейка»).

Исходники — svg в этой папке, нарисованы вручную в поле 192×192 (внутри — сетка 96×96, растянутая `transform="scale(2)"`, чтобы координаты фигур совпадали с прежним черновиком). Рабочие PNG в родительском каталоге — 96×96 (1x) и 192×192 (@2x), с прозрачностью, тем же приёмом, что и у катана с монополией: Chromium открывает svg на скрытой странице, рисует на `<canvas>` через `drawImage`, `canvas.toDataURL('image/png')` сохраняется на диск — альфа-канал сохраняется полностью (проверено по IHDR: цветовой тип 6, RGBA, у всех десяти файлов).

Стиль — тот же плоско-объёмный: мягкая размытая тень снизу, градиентная заливка для объёма, полупрозрачный белый блик сверху слева, без белого фона и без неоновых цветов. Салатовый акцент проекта (`#d2f76b` из `style.css`) использован точечно — как и у остальных значков, не залит сплошняком.

- 2048: золотая квадратная плитка со скруглёнными углами (как настоящая плитка игры), число «2048» тёмно-коричневым — единственное исключение про текст, число и есть символ игры.
- Судоку: планшет-подложка с толстой тёмной рамкой и сеткой 3×3, одна клетка выделена салатовым, в нескольких клетках — точки вместо цифр (условно, без читаемого текста).
- Блоки: три цветных изометрических кубика (бирюзовый, коралловый, фиолетовый), сложенные пирамидкой — у каждого видны три грани для объёма.
- Три в ряд: три одинаковых зелёных ромба-самоцвета в ряд с гранями-бликами и вспышкой (свечение и звёздочка) над средним.
- Змейка: короткое тело из зелёных квадратных сегментов, голова с двумя глазами, рядом красное яблоко с листиком.
